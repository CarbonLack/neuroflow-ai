START HERE / 从这里开始
========================

1. Keep this entire folder together. Do not move an individual project away
   from its raw, derived, results, and exports folders.
2. Double-click ..\START_NEUROEPHYS_AI.cmd. It repairs project paths for the
   current drive/computer and opens the Full application.
3. In the App choose Import/Open Project, then select a neuroflow_project.json
   under 03_Example_Projects.
4. Start with 03_Example_Projects\Quick_Demos for a fast tutorial.
5. Use 03_Example_Projects\Standard_Benchmark_20min_v2 for the complete
   Tetrode and Neuropixels benchmark collection.

这是一个整体可迁移的科研工作区。复制到新电脑后，先双击根目录的
START_NEUROEPHYS_AI.cmd，它会自动按当前盘符重新绑定样例项目路径。

Folder map:
- 01_Application: runnable Full App and installer.
- 02_Source_Code: clean Git repository with complete history.
- 03_Example_Projects: actual reusable example data and finished results.
- 04_User_Projects: destination for new work; initially empty.
- 05_Research_Data_Catalog: external real-data inventory only.
- 06_Documentation: user, scientific, developer, and handover documents.
- 07_Validation_and_Results: release and scientific validation evidence.
- 08_Manifests_and_Recovery: checksums, file inventory, path repair, recovery.
