USER PROJECTS
=============

Create or import new projects here. Use one directory per experiment/session.
Keep raw inputs read-only, derived intermediates under derived, final tables and
figures under results/exports, and project-specific notes beside the manifest.

This directory is intentionally empty in the clean transferable workspace.
The launcher creates Runtime_Workspace here for logs, caches and projects made
inside the App, keeping all generated state within the transferable root.
