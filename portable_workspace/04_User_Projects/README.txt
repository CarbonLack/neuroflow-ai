USER PROJECTS
=============

Create or import new projects here. Use one directory per experiment/session.
Keep raw inputs read-only, derived intermediates under derived, final tables and
figures under results/exports, and project-specific notes beside the manifest.

Apart from Runtime_Workspace, this directory is intentionally empty in the clean
transferable workspace. The launcher uses Runtime_Workspace for logs, caches and
projects made inside the App, keeping generated state within the portable root.
