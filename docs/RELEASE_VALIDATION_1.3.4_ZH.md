# v1.3.4 验收与使用边界

本版恢复首次打开的分步骤引导：研究者可选择学习或稍后再说，也可勾选“不再提醒我”。每个分析步骤有独立引导；之后用页面上的“本步引导”按钮或“帮助 → 当前步骤新手引导”（F1）重开。窄窗口不隐藏该步骤按钮。

AI 对话按项目与 11 个分析步骤分别保存到项目内的 `ai/conversation.json`。右侧和展开窗口使用左右聊天气泡；跨步骤搜索可找回旧对话，但在查看其他步骤历史时不能错用当前步骤的上下文继续提问。支持预览确认后向 Harness SDK、OpenAI-compatible Chat 或 Responses 的图像模型提交当前 PNG。图像请求的协议测试通过；**本机并未取得机构模型的真实看图回复**，实际是否成功仍依赖模型和服务具备视觉能力。

行为页默认提供两种行为谱：一张按动物分行，一张将所选动物的行为类型分行；可设起点与 10 秒、30 秒、1 分钟、5 分钟、20 分钟或全程窗口。图中的竖线是瞬时事件；只有明确的持续时间或配对开启/关闭事件才画为区间。旧行为摘要保留为可选视图。对于不含动物标识的单动物项目，不推断或拼接其他项目的身份。
