# 科研作图默认参数与依据

核对日期：2026-09-14。适用 NeuroEphys AI 1.2.1。此处区分期刊要求与软件的设计选择；没有一套适用于所有期刊的强制通用模板。

## 默认参数

| 项目 | 科研通用（默认） | Nature 投稿参考 |
| --- | --- | --- |
| 西文字体 | Arial | Arial |
| 中文缺字回退 | Microsoft YaHei；再回退 DejaVu Sans | 同左；投稿时仍需英文标签 |
| 横纵轴标题、刻度、图例 | 8 pt | 7 pt |
| 子图标题 | 9 pt | 7 pt |
| 轴线与刻度线宽 | 0.75 pt | 0.75 pt |
| 数据曲线线宽 | 0.8 pt | 0.8 pt |
| 主刻度长度 / 方向 | 3 pt / 向外 | 同左 |
| 网格 | 默认关闭，可打开 Y 主网格 | 同左 |
| 上、右边框 | 默认隐藏，可重新显示 | 同左 |
| 背景 / 文字 | 白色 / #222222 | 同左 |
| 分类色 | 浅紫 #B7A0C7、柔绿 #A4CBA0、浅赭 #D4BB91、灰蓝 #9EAFC5 | 同左 |
| 位图导出 | 600 DPI，可调整 | 同左；按目标刊物核对格式 |
| 矢量 | SVG 保留文本；PDF 使用 TrueType 字体 | 同左 |

字体大小和线宽以 **最终输出尺寸** 为准，不能仅凭屏幕放大后的观感判断。科研通用的 8 pt 不满足 Nature 的 5–7 pt 限制，因此单独提供 Nature 参考预设，不把通用预设冒充 Nature 模板。Nature 单、双栏尺寸入口为 89 mm / 183 mm；编辑器选择尺寸后，使用编辑器自身的“按当前样式导出”，保留所选物理宽度。

## 官方依据与设计边界

1. [Nature 最终稿要求](https://www.nature.com/nature/for-authors/final-submission)：偏好 Arial / Helvetica；普通标签 5–7 pt；最终尺寸线宽 0.25–1 pt；单栏 89 mm、双栏 183 mm；矢量文字和线条不应转成不可编辑的轮廓。0.75 pt 轴线与 0.8 pt 曲线是我们在该区间内选取的值，不是 Nature 唯一指定值。
2. [PLOS Medicine 图件要求](https://journals.plos.org/plosmedicine/s/figures)：图内文字要求 Arial、Times 或 Symbol，8–12 pt。通用预设采用该范围下限以保持紧凑；仍需按具体期刊核对文件类型、分辨率和版面。
3. [Nature 图件规范](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)强调可访问配色；[Nature 初投稿说明](https://www.nature.com/nature/for-authors/initial-submission)提醒避免红绿作为唯一对比及彩虹色标。默认柔和紫绿方案来自用户提供的视觉参考，是产品配色选择，未经全面色觉模拟验证，不能宣称保证色觉无障碍。另保留高对比分类型配色：蓝 #0072B2、朱红 #D55E00、橙 #E69F00、绿 #009E73。不能只靠颜色传递组别，应保留标签或线型。
4. [Matplotlib 色图指南](https://matplotlib.org/stable/users/explain/colors/colormaps.html)区分连续、发散和分类色图。统一样式只重映射本软件已知的分类色，不改热图的归一化、数值范围或发散含义；也不把连续数值着色的散点强制改成分类色。现有定量色图保留，必要时可单独选择 viridis 等合适色图。
5. [GraphPad 官方“修改一个、部分或全部数据集”说明](https://www.graphpad.com/guides/prism/latest/user-guide/changing_one__some_or_all_data.htm)用于参考调整范围的交互方式；未复制其代码或资源。

默认无网格、隐藏上右边框、3 pt 向外刻度、深灰文字、无图例边框，是减少非数据装饰的产品设计选择，并非全部期刊的强制要求。App 界面仍为原紫黑主题，白色仅用于科研图纸。

## 在 App 中操作

打开“图表工具 → 图形设置”，或双击图中的绘图区。

- 左侧现在显示“子图 + 实际图名”。子图是一整块绘图区；X / Y 范围在右侧单独一页，色标也会注明。
- “当前对象”：标题、范围、位置、轴线、刻度、网格、参考线和图例分页；同页参数并排呈现。曲线、柱、散点等仍可展开逐个选取。
- “统一样式”：先选预设，再修改参数，最后选择“当前子图”“当前整图”或“项目所有图”，点击“应用并预览”。
- 当前子图与整图的统一样式覆盖保存在当前图类型下；项目统一样式适用于之后生成的图，包括 Python 导出。明确选择“项目所有图”会清除局部统一样式覆盖，以保持一致。
- Ctrl+S 保存项目后，重新打开仍能恢复统一样式。原先已导出的文件不会被自动改写；需要重新导出到用户指定位置。
- “当前对象”的精细元素编辑只作用于当前画布，须导出保存成品，不等同于项目统一样式。不要把临时曲线编辑误认为所有后续重绘都会保留。

统一样式不改变原始数据、分析算法、横纵轴范围、单位、对数尺度、时间对齐、色标范围或统计结果；不同量纲的子图绝不会被统一成相同数值范围。
