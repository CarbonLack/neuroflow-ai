受控 AI 助手
============

Harness 项目对话、图像解读与 Study（v1.3.3）
----------------------------------------------------------------------

已配置机构 DeepSeek Harness 时，在 AI 设置点击“读取本机 DeepSeek Harness 配置”，
选择 Harness SDK。App 通过官方 dsh 运行时请求模型，不读取或复制机构密钥。
Harness 须单独安装并完成账号配置，参考 https://deepseek.com/harness/en/ 。

首次发送预览中允许“按需查询项目数据、结果与历史对话”后，可直接询问指定 Unit
指标、事件时间、结果表或当前图表信息。模型可通过 MCP 分页查询真实值，并给出
查询证据；不是只读取固定摘要。默认图表信息不等于截图像素，原始电压不经此查询接口发送。

例如：“查询 unit_id=25 的 SNR 和 ISI 违规率，解释这些证据是否足够。”
或：“回顾这个项目里我们之前关于同步误差的讨论。”每个项目的对话独立保存，
并可在展开窗口按“项目分析、图表解读、方法问答、通用问题、早期对话”分类；
新会话默认归入项目分析，用当前图发起的新会话自动归入图表解读，分类可手动更改。
首问自动命名，也可重命名；搜索覆盖分类、标题和问答正文。旧版记录保留在“早期对话”。
此分类只作用于 NeuroEphys AI 项目内的对话，不会更改外部 Harness 网页的“未分组”。
每次只把当前会话的近期内容带入模型。会话存入项目 ``ai/conversation.json``，
重开项目仍可读取。新功能须注册工具及参数权限，
AI 不会因此获得任意代码或文件访问权限。分析提案经用户确认后才运行。

需要 AI **真正看图** 时，点击右侧“解读图”或展开窗口的“解读当前图”。App 在内存中
渲染当前图为 PNG，先显示与发送内容一致的预览；只有确认后才经官方 Harness SDK 的
图像消息块发送。模型应区分可见趋势和项目计算出的准确数值。对话档案只保存图名和
发送记录，不保存 PNG 字节。若当前图含波形、文字或标签，预览时请自行检查。
普通兼容 API Provider 暂不支持此入口，不会假装模型已经看到图。此能力也不授予
Harness 任意文件读取权限。

如果提示 ``NVM4306``，本机 Node/NVM 安全启动器已拦截 ``dsh``，请求并未到达模型。
先在终端运行 ``dsh --version`` 核对，再按 NVM 提示由管理员执行 ``nvm reshim``
或修复可信启动器；不要通过复制机构密钥来绕过 Harness。

输入框 **回车发送**，**Shift+回车换行**。未打开项目时也可问通用科研知识或其他问题；
这类无项目对话保存在用户工作区的 ``ai/general_conversation.json``，不混入实验项目。
打开项目后，AI 必须区分一般知识、版本化软件教程和项目实测证据。关于软件操作的
具体步骤可通过内置教程检索获得。模型没有检索外部实时资料时，不得把当前事实或
未核对的文献说成已查证。

保存多 Session Study 后，当前项目摘要会登记其随机 Study ID、动物/Session 数、所选
条件、验证层级和已有指标。AI 可以解释这些结果，也可以在协作模式提出受控的
``run_multi_session_analysis``；App 仍会核对本机 Study、参数和用户确认。Study 名称、
本地路径、动物/Session 明细、轨迹大数组和原始电压不会进入云端摘要。AI 还必须区分
按 Session 留出与按动物留出，不得把同号 Unit 当成跨 Session 的同一细胞。

每轮使用发送时的项目快照，完成分析后下一轮读取新结果。切换项目或服务设置会
重新确认可发送内容。没有待确认任务时隐藏空计划表，保留更多聊天空间。

先看懂，再看细节
------------------

AI 对话默认使用 **简洁阅读**。聊天卡片首先给出结论，最多保留三个关键点，并将
“已读取多少项目证据”“是否提出待确认操作”“下一步”和重要警告分开显示。模型的
完整回答、科学解释、限制、证据编号和候选操作没有被删除，点击 **查看完整说明与依据**
即可打开。右侧助手和展开后的独立对话窗口都可以在 **简洁阅读／完整内容** 间切换，
选择会被记住。

模型本身也遵循统一的清晰表达规则，而不是依赖界面事后删字：先直接回答问题，再按需
说明“为什么”“你现在可以怎么做”和“需要注意”。内部字段必须先翻译成科研含义，
数字必须说明对象、单位和意义。简单问题保持短小，结果解释和操作指导允许适当展开；
清晰度优先于固定字数。用户明确要求详细时，回答仍先给结论，再分层展开。

这种分层只改变阅读方式，不降低科学约束：不能支持的结论、数据限制和关键警告仍会在
简洁卡片中出现；原始完整内容继续随项目保存在 ``ai/conversation.json``，用于复核与审计。
AI 默认不复述内部查询过程、接口细节或长参数清单，除非用户明确要求详细说明。

AI 助手位于分析工作区右侧，可以收起。它接收本地确定性代码生成的小型结构化项目
摘要，原始电压数组不会进入模型请求。

三种模式
--------

手动模式
   不发送模型请求，全部科学控件保持可用。

助手模式
   模型解释当前页面、参数、警告和后续选择，无执行权限。

协作模式
   模型可以提出白名单工具调用。NeuroEphys AI 检查 JSON 结构、前置条件、依赖、
   工作流顺序和风险，随后弹窗，由用户决定是否执行。

模型 Provider
-------------

当前 Provider 层支持 DeepSeek、OpenAI Responses、OpenAI 兼容服务、机构托管
harness、实验室/私有兼容服务和本机 Ollama。服务地址、模型、超时、重试、流式输出和推理选项均可配置。API 密钥保存在
操作系统凭据区或当前会话中，不写入项目、日志、导出文件和 Git。

本机已部署 DeepSeek Harness 时，点击 **读取本机 DeepSeek Harness 配置**。应用只读取
Provider、``/v1`` 地址、模型列表和环境变量名，不读取 Harness 凭据文件。内网 HTTP
必须对该 Provider 显式启用，然后用“检测服务状态”验证模型列表和延迟。

Harness SDK 路径调用本机官方 ``dsh`` 运行时，不是用界面自动化操作 Harness 网页，也不
把机构密钥复制到 App。Harness 负责模型访问；NeuroEphys AI 负责项目快照、MCP 查询、
工具校验、科学约束、审计记录和用户确认。其他用户仍可选择通用 API 或 Ollama Provider。

发送内容预览
------------

在线请求前，点击 **预览云端数据** 可以查看准备发送的字段类别。用户可以删除可选
字段或取消请求。本地路径、原始电压、大型数组和 API 密钥会被排除。

科学解释结构
------------

结果说明分为：已观察结果、统计证据、可考虑的生物学解释、当前证据无法支持的结论、
数据和方法限制、建议增加的验证。模型输出用于辅助判断。工具名称、参数和工作流节点
必须通过本地 JSON Schema 与规则检查。

上下文协议使用版本号。每次请求都包含工作流顺序、当前节点、已有输入、分析摘要、
失败/跳过节点、输出清单和 UI 位置；新增模块只要把结构化结果注册到项目摘要与工具白名单，
AI 即可读取，同时仍不能直接读取原始电压、任意本地文件或调用未注册功能。

本机 Ollama
-----------

单独启动 Ollama，下载兼容模型，在设置中选择本机 Provider。默认兼容地址为
``http://127.0.0.1:11434/v1``，该模式不会向云端发送项目摘要。

.. warning::

   配置 Provider 不代表已经授权发送项目内容。每次在线请求都会显示发送字段类别，
   并等待用户确认。
