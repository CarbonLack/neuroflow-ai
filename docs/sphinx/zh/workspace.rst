认识工作区
==========

打开项目后，中间显示当前分析，左侧选择模块，右侧查看助手、帮助和日志。
选择模块或“下一步”只切换页面；底部 **运行当前所选分析** 才开始计算。

找到功能
--------

按 **Ctrl+K** 打开“查找操作”，输入“保存”“sorting”“图形”或模块名。
使用上下键选择，按 Enter 打开。暂时不可用的操作会显示原因。
首页和 **文件 → 最近的项目** 可继续最近打开过的项目；文件已移动的条目会变灰。

菜单承担固定入口：文件管理项目，编辑设置图形、AI 和 sorter，视图控制窗口，
分析运行任务，帮助打开教程。运行完整流程仍在分析菜单；可以只运行需要的模块。

给图表留出空间
--------------

* **Ctrl+B**：缩略或展开左侧流程；窄窗口会自动缩略。
* **Ctrl+J**：显示或关闭右侧助手。三栏可以同时存在，拖动分隔线调整宽度。
* **图表工具**：展开绘图样式、子图选择、编辑/保存和波形时间窗等控件。
  收起后图表仍可用工具栏缩放、平移和保存。
* **单独放大**：查看选中子图；**显示全部** 回到完整图。
* **F11**：全屏。**视图 → 恢复三栏默认布局** 恢复默认宽度。

图表工具在较窄的分析栏自动换行，复杂分析面板仍可滚动查看。
标题栏显示项目名；将鼠标停在名称上可查看项目路径。

教程与提示
----------

**帮助 → 教程中心**（Ctrl+Shift+H）按任务查找操作，也可从首页进入。
每项分为“操作步骤”“参数说明”“遇到问题”；点击“打开对应页面”进入相关模块，
计算仍由运行按钮启动。**A− / A+** 调整阅读字号，“标为已读”保存阅读记录。
教程是独立窗口，可以一边阅读一边操作工作区。

   <a href="../assets/neuroephys-tutorial-zh.png"><img class="product-shot" src="../assets/neuroephys-tutorial-zh.png" alt="教程中心：任务目录、短步骤和相关页面入口"></a>

按 **F1** 查看本步引导。勾选“不再自动弹出分步骤引导”可关闭自动提示；
之后仍可手动打开，或在帮助菜单重新开启。完整任务文字见 :doc:`task-guide`。

看懂运行与保存
--------------

底部进度针对本次任务：只运行一个模块时是 0/1 到 1/1。执行日志显示在右侧“日志”。
已完成阶段会保存结果；修改后可以随时 Ctrl+S。切换项目或退出时，未保存的修改会提醒处理。
导出的图片、表格与中间结果位置见 :doc:`provenance`。
