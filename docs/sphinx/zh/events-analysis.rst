行为同步与事件对齐分析
======================

行为设备和电生理设备通常具有不同起点，长记录中还可能出现时钟漂移。共同 TTL 序列
提供两个时钟之间的匹配锚点。

导入和映射事件
--------------

在 **06 事件同步** 页面选择行为文件和解析器，建立数字事件码与事件名称的映射，
指定电生理 digital input 通道以及同步开始/结束码。对齐前先检查事件数。任务事件和
同步事件默认分开显示。

判断对齐质量
------------

检查匹配锚点数、未匹配脉冲、残差分布、残差随时间趋势和拟合的时钟变换。平均残差
较小仍不能抵消整段漏脉冲或非线性误差。

Raster 与 PSTH
--------------

选择事件码或条件名称、对齐窗口、bin 宽、基线窗和响应窗。软件分别筛选每个条件，
并保存纳入数量和排除原因。

Raster 每行对应一个纳入事件，颜色表示条件。PSTH 显示条件均值和标准误，淡色区域
标出实际基线窗和响应窗。群体热图采用基线 z 分数和发散色带。

必须检查
--------

* 解释左右、成功/失败曲线前，核对事件码含义。
* 查看两个条件的事件数量和排除原因。
* 先检查单 Unit，再使用群体平均。
* 确认基线窗没有覆盖响应期。
* 多 Unit 或多时间点检验时，核对 FDR 输入集合和校正方式。

图中的“事件序号”只表示纳入事件的顺序。只有项目已建立有效 trial 表时，页面才会
使用 trial 名称。
