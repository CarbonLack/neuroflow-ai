# Roadshow presentation

`NeuroEphys_AI_Final_Roadshow_v1.4.0.pptx` is the reviewed competition and
external-demonstration deck for NeuroEphys AI 1.4.0.

- Format: 16:9, 11 slides
- Planned speaking time: approximately 8 minutes
- Includes speaker notes and source notes
- Uses product screenshots and locally generated teaching-project results
- Teaching simulations demonstrate the workflow and do not establish biological
  conclusions

The deck completed five render-and-inspect review rounds. The detailed review log
is stored in the canonical project collection under
`07_Validation_and_Results/Roadshow_PPT_Review_20260923/REVIEW_LOG.md`.

## Speaker script

The presentation is accompanied by two synchronized script formats:

- `NeuroEphys_AI_Roadshow_Speaker_Script_v1.4.0.docx`: the reviewed rehearsal
  document, with an exact 8:00 timing table, slide-by-slide narration, transition
  and demonstration cues, a fallback demonstration route, and suggested answers
  to common judge questions.
- `NeuroEphys_AI_Roadshow_Speaker_Script_v1.4.0.md`: the same content in a
  version-control-friendly plain-text format.

The DOCX was rendered to 16 pages and visually inspected page by page. The script
keeps implemented features, validated evidence, inference, and future scientific
validation clearly separated.
