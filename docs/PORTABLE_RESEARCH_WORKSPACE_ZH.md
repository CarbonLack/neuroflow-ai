# NeuroEphys AI 可迁移科研工作区

`codex_neuroephys_ai` 是一个可整体复制的科研工作区，不是快捷方式或只有索引的备份目录。

## 可以带到新电脑的内容

- Full 版可运行 App 与 Full 安装包。
- 完整源代码工作树、Git 历史和恢复 bundle。
- 两类 20 分钟标准模拟数据：Tetrode 与 Neuropixels。
- 行为、事件、ground truth、候选 sorting、中间产物和最终图表。
- 快速教学项目、产品文档、验证报告、文件清单和校验值。

## 到新电脑后

1. 完整复制根目录，不要只复制其中一个子目录。
2. 双击根目录的 `START_NEUROEPHYS_AI.cmd`。
3. 启动器会根据新位置重新绑定项目的原始数据路径，然后打开 App。
4. 在 App 中选择“导入项目”，打开 `03_Example_Projects` 下的 `neuroflow_project.json`。

## 不在这个可迁移集合内的内容

王淑霏原始真实数据和历史版构建缓存不属于演示或继续开发的必需输入。它们保持在外部存档位置，并在清单中标记。这些文件不影响 App、源码、公开样例和已导出结果的使用。若要重新分析王淑霏真实记录，则需要另外复制该真实数据目录。

## “完整”具体指什么

复制整个 `codex_neuroephys_ai` 后，可在另一台 Windows 电脑上完成以下工作：

- 直接运行 Full App，或使用 Full 安装包安装；
- 打开两类 20 分钟标准样例及快速教学样例；
- 读取样例中的神经数据、行为事件、ground truth、中间结果和导出图表；
- 使用完整 Git 历史继续开发，并通过离线 bundle 恢复仓库；
- 查看产品、科研方法、开发、验证和项目交接文档。

这里的“完整”不表示把实验室所有独立原始数据都复制一遍。真实原始记录是独立科研资产，只有在重新分析对应实验时才需要单独复制。工作区不会通过快捷方式伪装成已经包含这些数据。

## 推荐目录边界

- `codex_neuroephys_ai`：唯一正式、可整体复制的产品与样例工作区。
- `AI大赛`：独立保存真实原始数据和比赛提交材料，不与公开样例重复。
- `Pending_Deletion_After_Consolidation_*`：迁移后的历史冗余隔离区，确认无回滚需求后可删除。
