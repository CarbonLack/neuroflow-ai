Traceable design

方法有出处，产品不照搬

Methods are sourced; the product is independently designed

本页记录每类资料如何影响 NeuroFlow。官方文档决定 API，原始论文决定方法语境，二次文章只作为检索线索。

This page records how each source informs NeuroFlow. Official docs define APIs, original papers define scientific context, and secondary articles serve only as discovery aids.

引用与独立实现原则

Attribution and independent implementation

  1. External interfaces, prose, screenshots, figures, and code are not copied.
  2. Official documentation is preferred for software capability claims.
  3. Original papers are preferred for scientific methods and limitations.
  4. NeuroFlow writes its own adapters, validation logic, interaction, figures, and tutorials.
  5. Case templates are labelled separately from paper reproductions.

主要原始来源

Primary sources

  • SpikeInterface documentation — recording, preprocessing, sorting, postprocessing, quality and export modules.
  • SpikeInterface preprocessing — lazy chains, pipeline objects, phase shift, referencing, whitening and bad-channel handling.
  • SpikeInterface postprocessing — SortingAnalyzer extensions and dependency-aware computation.
  • SpikeInterface quality metrics — contamination, completeness, drift, amplitude, SNR and dependency requirements.
  • SpikeInterface comparison — ground-truth performance, symmetric Hungarian Unit matching, and multi-sorter consensus.
  • Kilosort4 documentation — parameters, diagnostics and exported files.
  • Kilosort4 parameter guidance — channel count, batch size, drift blocks and detection thresholds.
  • MountainSort5 0.5.9 — current CPU sorter package, Isosplit dependency, SpikeInterface I/O, and three sorting schemes.
  • Neo data model — unit-aware signal, spike, event and epoch objects.
  • Elephant function reference — spike-train, spectral, synchrony and spike-field analysis.
  • Elephant spike-train statistics — rates, ISI statistics, Fano factor and trial-aware inputs.
  • Folschweiller & Sauer, 2023 — behavioral-state-dependent respiration modulation of prefrontal activity.
  • International Brain Laboratory Brain-Wide Map — public-data organization and analysis examples.
  • IBL 2025 Brain-Wide Map release — official release scope, identifiers, fields, license and access route.
  • IBL spike-sorting data guide — official PID-based ALF loading example used to select the validation insertion.
  • IBL Brain-Wide Map analysis repository — source analysis code and reproducibility context for the Nature paper.
  • IBL trials-data guide — ALF trial fields, behavior performance, filtering, psychometrics and task QC.
  • Buzsáki Lab Databank — public raw and processed extracellular recordings, behavior and metadata.
  • Buzsáki Lab data structure and format — Buzcode spikes, behavior, trials, LFP and session organization.
  • DANDI 000552, fixed version — NWB validation session with Units, reward, position, state and ripple objects.
  • Huszár et al., 2022 — source paper and code/data availability statement for DANDI 000552.
  • Buzcode — public processing and analysis functions cited by the source study.
  • DANDI documentation — versioned Dandisets, NWB access and archive provenance.
  • GraphPad Prism: ways to change a graph — official object-selection, graph-format, and axis-format interaction model used only as a product-design reference.
  • GraphPad Prism: graph shape and size — distinction between canvas size, display zoom, and exact axis length.
  • GraphPad Prism: major and minor ticks — interval, direction, length, and minor subdivision concepts.
  • GraphPad Prism: grid lines — regular and additional grid-line concepts.
  • GraphPad Prism: frame and axes appearance — independent axis/frame visibility, color, and thickness concepts.
