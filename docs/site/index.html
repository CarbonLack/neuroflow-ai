Local-first electrophysiology workbench

NeuroFlow

将原始多通道记录、Kilosort 与可替换 sorter、行为事件、Neo/Elephant 分析、统计和论文导出组织在一个可拆解、可检查、可复现的桌面工作流中。

A local desktop workflow that connects raw multichannel recordings, Kilosort and replaceable sorters, behavior, Neo/Elephant analyses, statistics, and reproducible publication output.

产品原则

Product principles

看得见

Visible

每一步显示输入、参数、方法、结果与风险，不把分析压缩成一个黑箱按钮。

Every stage exposes inputs, parameters, methods, results, and risks instead of hiding analysis behind one button.

换得掉

Replaceable

同一阶段可以更换 sorter 或从外部结果继续，AP、LFP 和行为模块不被强绑定。

Swap sorters or resume from external results without binding AP, LFP, and behavior modules together.

追得回

Traceable

项目保存来源、版本、参数、人工判断和导出文件，使图表能够回到分析证据。

Projects preserve sources, versions, parameters, decisions, and exports so figures remain linked to evidence.

五分钟开始

Start in five minutes

  1. 打开 NeuroFlow，选择“打开示例数据”。
  2. 在“原始质控”中查看波形、功率图和质量时间线。
  3. 在“预处理”中分别检查 AP 与 LFP 分支。
  4. 在“Spike sorting”中选择 Kilosort4 或当前可运行 sorter。
  5. 运行后继续查看 Unit、行为、Elephant、统计和机器学习结果。
  1. Open NeuroFlow and choose the bundled demo dataset.
  2. Inspect traces, channel-frequency power, and the quality timeline.
  3. Review AP and LFP preprocessing branches separately.
  4. Select Kilosort4 or another available sorter.
  5. Continue through units, behavior, Elephant, statistics, and machine learning.
raw voltage → QC → AP/LFP branches → sorting → unit review
→ synchronization → behavior → neural methods → statistics → ML → export

能力边界

Capability boundary

NeuroFlow 调用经过验证的开源库进行计算，但软件不会把候选 unit 自动宣布为可靠单神经元，也不会把统计差异自动写成生物学结论。
NeuroFlow delegates computation to established open-source libraries, but it does not declare candidate units to be valid neurons or turn statistical differences into biological conclusions automatically.

AI 是可选助手；完整手动与引导流程不依赖大模型。高级 Elephant 模式检测仍列为待验证目录，而不是虚假的“一键可用”。

AI is optional. Manual and guided workflows do not require an LLM. Advanced Elephant pattern detection remains catalogued until dedicated validation exists.
