Final demonstration and offline fallback
========================================

**Help → Final demo readiness** turns the competition brief into an evidence
checklist. It reports only artifacts that actually exist: a restorable project,
analysis evidence, exported figures, publication storyboard, AI configuration,
sorter availability, and offline documentation.

Suggested 5–10 minute sequence
------------------------------

1. Practical problem and users.
2. Create or import a project and show provenance.
3. Show QC, three-sorter comparison and event synchronization.
4. Show raster/PSTH, statistical evidence and beginner explanations.
5. Show English main/supplementary figures, panel letters and caption drafts.
6. Show redacted AI context, registered tools and confirmation boundaries.
7. Close with measured benefits, limitations and an offline fallback.

Keep the full installer, standard installer, portable edition, offline manual,
fully exported simulation and real-data projects, screenshots, and a short screen
recording together. Do not rerun a long sorter live. If the network is unavailable,
manual mode retains deterministic analysis and export.
