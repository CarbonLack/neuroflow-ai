NeuroFlow operation manual

Installation and runtime

The desktop application, scientific environments, sorter backends, and project data are separated so one failed tool does not prevent NeuroFlow from opening.

System requirements

  1. Windows 10/11, macOS, or Linux for the interface.
  2. Sufficient disk space for source data, normalized caches, sorter output, and exports.
  3. An NVIDIA GPU is recommended for Kilosort4; CPU sorters remain separate alternatives.

Desktop installation

  1. Install or unpack the NeuroFlow release.
  2. Start NeuroFlow without opening a Python console.
  3. Open Sorter Manager to inspect actual backends, versions, hardware requirements, and probe suitability.

Project storage

  1. The source is read-only. Generic binary data can be linked or copied into the project.
  2. A project contains neuroflow_project.json, derived results, sorter-native folders, exports, and audit logs.
  3. Keep the source path stable when using a link; copy the source for a self-contained archive.

External sorter environments

  1. A sorter is shown as runnable only after a real environment probe.
  2. Kilosort4 uses its installed Python/GPU stack; other sorters may use CPU, containers, or separate environments.
  3. NeuroFlow preserves exact failures and never substitutes another sorter silently.
