Method-aware integration

工具不是列表，方法必须接得上

Methods must connect, not merely appear in a tool list

SpikeInterface 负责记录与 sorting 主干，Neo 保存带单位的数据对象，Elephant 提供经过文档化的电生理分析，NeuroFlow 负责连接、解释、验证和追溯。

SpikeInterface provides the recording/sorting backbone, Neo carries unit-aware objects, Elephant provides documented analyses, and NeuroFlow connects, explains, validates, and records them.

方法架构

Method architecture

NeuroFlow project
├─ SpikeInterface: Recording / Sorting / SortingAnalyzer
├─ Neo: AnalogSignal / SpikeTrain / Event / Epoch
├─ Elephant: spike, spectral, synchrony, spike-field
├─ SciPy + statsmodels: signal processing and inferential tests
└─ NeuroFlow: adapters, guardrails, UI, provenance, figures

用户仍可以完全手动运行、跳过节点或导入外部结果。Neo/Elephant 不改变项目的原始文件，只读取标准化视图。

Users can still operate manually, skip stages, or import external results. Neo/Elephant read standardized views without altering source files.

呼吸调制案例

Respiration-modulation case

案例参考 Folschweiller 与 Sauer（2023）的分析结构：分状态呼吸 PSD、呼吸-LFP coherence、呼吸相位下 gamma 振幅，以及 spike 相位锁定。NeuroFlow 使用自己生成的三状态模拟数据和自己的图形实现。

The case follows the analytical structure of Folschweiller and Sauer (2023): state-specific respiration PSD, respiration-LFP coherence, gamma amplitude over respiration phase, and spike phase locking. NeuroFlow uses its own three-state simulation and figures.

不是论文复现：Not a paper reproduction: 没有使用原论文数据，不复制原图，也不声称得到相同数值或生物学结论。 The original data and figures are not used, and matching numerical or biological conclusions are not claimed.

统计护栏

Statistical guardrails

Hierarchy

Trials, units, sessions, and animals are recorded as distinct sampling levels.

Pairing

Baseline-response and repeated observations remain explicitly paired.

Circular evidence

Phase locking reports vector strength, a Rayleigh approximation, and circular-shift surrogates.

Multiplicity

Raw p values, effect sizes, confidence intervals, and corrected values remain visible together.
