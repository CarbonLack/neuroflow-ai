逐阶段操作手册

Stage-by-stage operating manual

每一项都说明为什么运行、需要什么输入、参数改变会造成什么后果，以及完成后应检查哪些证据。下拉菜单中的每个子分析可以单独运行；共享前提只计算一次并保存在项目中。

Each stage states why it is run, which inputs it needs, how parameters change the result, and which evidence must be checked. Every analysis listed in a stage menu can run independently; shared prerequisites are cached once in the project.

01 · Data and project / 数据与项目

Purpose / 目的
Prevent a wrong sampling rate, channel count, dtype, scale, or stream from corrupting every downstream time and voltage value.
Inputs / 输入
Read-only acquisition source, probe/electrode description, sample rate, channel order, voltage scale, behavior log, and optional TTL file.
Run / 运行
Select the adapter for generic binary, Intan, Open Ephys, SpikeGLX/Neuropixels, Blackrock, Plexon, TDT, NWB, IBL ALF, or Kilosort/Phy. Inspect the first trace window immediately.
Evidence / 证据
Project manifest, exact source path, file-size divisibility, duration, channel inventory, unit conversion, and import log.

02 · Raw QC / 原始质控

Purpose / 目的
Find broadband noise, clipping, line-frequency contamination, discontinuities, and channels that could corrupt referencing or sorting.
Sub-analyses / 子分析
Zoomable raw traces; channel RMS and labels; channel × frequency power; time-resolved RMS/clipping timeline.
Parameters / 参数
Time start, visible window, first channel, channel count, and display gain affect viewing only. QC preview duration changes the amount of data sampled, not the original file.
Decision / 决策
A flagged channel is a candidate. Confirm it in traces and spectra before exclusion; preserve the manual decision.

03 · Preprocessing / 预处理

Purpose / 目的
Create separate AP/sorting and LFP branches without treating preprocessing as one fixed recipe.
AP branch
Preview high-pass/band-pass and referencing on the same segment. Confirm edge effects, polarity, artifacts, and whether the selected sorter already filters or whitens internally.
LFP branch
Low-pass before downsampling, preserve physical units, inspect line noise and transient artifacts, and record the new sampling rate.
Safety / 安全
The preview never overwrites raw data. Avoid applying whitening twice and confirm bad channels before common reference.

04 · Spike sorting

Purpose / 目的
Assign detected extracellular events to candidate units while retaining each algorithm's native evidence.
Selection / 选择
Kilosort4 targets dense probes and uses a GPU template-matching pipeline. MountainSort5 supplies CPU Schemes 1/2/3. SpyKING CIRCUS 2, Tridesclous 2, Simple, and Lupin run through their registered SpikeInterface implementations.
Parameters / 参数
For Kilosort, batch_size controls samples per batch, nblocks controls spatial divisions used in drift correction, and detection thresholds trade sensitivity against noise. For MS5, scheme, detection threshold, and training duration alter the CPU workflow.
Outputs / 输出
Native result folder, full run log, exact version and settings, plus NeuroFlow's stable Unit → spike-times-in-seconds schema. Kilosort-only drift/template/file views are never shown for another sorter.

05 · Unit QC / Unit 质控

Purpose / 目的
Separate candidate single units, multi-unit activity, duplicates, unstable clusters, and noise using multiple lines of evidence.
Per-unit views / 单元视图
Waveform and peak channel, autocorrelogram, ISI distribution, firing rate, SNR, amplitude, and stability over recording time.
Dependencies / 前提
Some metrics require waveforms, templates, amplitudes, spike locations, noise levels, or principal components. A missing prerequisite is reported rather than silently replaced.
Decision / 决策
No one metric certifies a neuron. Thresholds, manual labels, and reasons for exclusions remain in the audit trail.

06 · Synchronization / 事件同步

Purpose / 目的
Map behavior-device time to electrophysiology time before asking whether neural activity leads or follows an event.
Inputs / 输入
Behavior CSV with trial and behavior timestamp; optional TTL CSV with matching pulse times recorded by the ephys system. Seconds, milliseconds, and sample indices are accepted explicitly.
Method / 方法
Pair rows in order, fit ephys_time = offset + slope × behavior_time, then create a unified trial table. No TTL file means the clocks are declared shared, not inferred.
Evidence / 证据
Event counts, matched pairs, missing pulses, offset, drift in ppm, residual-vs-trial plot, mean and maximum absolute residual.

07 · Behavior / 行为分析

Purpose / 目的
Check whether trial counts, balance, performance, missing values, or reaction times can explain apparent neural differences.
Inputs / 输入
The synchronized trial table: condition, event type, choice/outcome, reaction time, stimulus variables, and exclusion flags.
Sub-analyses / 子分析
Condition counts, reaction-time distributions, psychometric curves when stimulus and choice fields exist, and explicit valid/excluded trial counts.
Decision / 决策
Inspect the number of trials behind each point. Behavior QC is completed before neural decoding.

08 · Neural workbench / 神经活动

Purpose / 目的
Keep event responses, spike-train statistics, LFP analysis, and spike-field coupling as separate objects with explicit assumptions.
Independent runs / 独立运行
One Unit raster/PSTH; Elephant firing/ISI/Fano/CCH; correlation, STTC and spike-train distances; LFP PSD/band power; coherence/phase lag; spectrogram; spike-field phase locking; respiration method-validation case.
Parameters / 参数
Alignment window, bin width, smoothing, frequency band, segment length, phase reference, and surrogate count alter different scientific questions and are stored per result.
Interpretation / 解释
Raster preserves trial variability; PSTH averages it. Spectral power, coherence, and phase locking are not interchangeable evidence.

09 · Statistics / 统计

Purpose / 目的
Define the sampling unit and repeated-measures structure before selecting a test.
Integrated methods / 方法
Paired t/Wilcoxon/permutation, Welch/Mann–Whitney, ANOVA/Kruskal–Wallis, Shapiro and Levene diagnostics, Pearson/Spearman, bootstrap CI, effect sizes, mixed-effects model, circular surrogate tests, FDR/Holm/Bonferroni.
Independent views / 独立视图
Effect and multiplicity; condition comparisons; distribution/correlation/mixed-model diagnostics; phase-locking surrogate; sampling hierarchy and decision record.
Warning / 警告
Units nested in sessions and animals are not automatically independent replicates.

10 · Machine learning / 机器学习

Purpose / 目的
Test whether trial-level neural features predict a label or continuous target without leaking information between train and test data.
Methods / 方法
Classification and regression model catalog, stratified/grouped cross-validation, permutation baseline, ROC/F1/confusion or R²/MAE, feature importance, PCA, clustering, and time-resolved decoding.
Parameters / 参数
Feature window, grouping variable, fold count, class balancing, random seed, and model hyperparameters are saved. Preprocessing is fit inside training folds.
Interpretation / 解释
Prediction above chance does not by itself prove a brain area encodes an abstract concept.

11 · Publication and reproduction / 论文与复现

Purpose / 目的
Keep every figure connected to its data, parameters, statistical table, software environment, and manual choices.
Figure controls / 图形控制
Click marks for values, toolbar zoom/pan, double-click an axis to edit labels and limits, select one subplot to enlarge/edit/export, and switch presentation style without changing source data.
Exports / 导出
Editable SVG/PDF, 300 dpi PNG, CSV tables, workflow JSON, provenance, environment versions, run logs, and a Methods draft.
Check / 检查
Verify units, error-bar definitions, color accessibility, statistical annotation sources, and whether each result has actually run.

Sorting workbench

选择 sorter 后仍需确认硬件、探针、参数和输出。Kilosort4 运行后可以切换真实的流程日志、漂移、振幅、模板、相似度、污染率与文件视图。

Selecting a sorter does not remove the need to verify hardware, probe, parameters, and output. Kilosort4 results expose pipeline logs, drift, amplitudes, templates, similarity, contamination, and files.

Kilosort4、MountainSort5 与其他已运行 sorter 会分别保存，再转换成统一的 Unit→秒级 spike times。比较视图使用 SpikeInterface 的事件匹配与 Hungarian Unit 匹配，显示算法间一致度、独有 Unit 和至少两个 sorter 支持的共识 Unit。

Kilosort4, MountainSort5, and other completed sorter outputs are retained separately and normalized to Unit-to-spike-times in seconds. The comparison view uses SpikeInterface event and Hungarian Unit matching to show agreement, unique units, and consensus units supported by at least two sorters.

中央分析区可独立上下滚动，并为科研图保留稳定的大画布。多面板图中的每个子图都可单独选择、放大、编辑和导出为 SVG、PDF 或 300 dpi PNG。

The central workspace scrolls independently and reserves a large, stable scientific canvas. Each subplot can be selected, expanded, edited, and exported independently as SVG, PDF, or 300 dpi PNG.

自动 cluster 是候选 unit，不是已经认证的单神经元。Unit 质控和人工复核不能省略。
Automatic clusters are candidate units, not certified single neurons. Unit QC and manual review remain required.
真实记录没有 ground truth，因此算法间一致不能被称为准确率。Precision、recall 与 F1 只在模拟或配对真值数据中显示。
Real recordings have no ground truth, so cross-sorter agreement is not accuracy. Precision, recall, and F1 appear only for simulated or paired ground-truth data.

示例项目真实包含前两个 CSV；在软件第 6 页点击“导入 / 替换行为与 TTL”即可查看路径、导入自己的文件并检查对齐图。只提供一个含 time_seconds 的事件文件时，NeuroFlow 会明确记录“共用时钟”假设。

The demo project includes both CSV files. In stage 06, choose “Import / replace behavior and TTL” to inspect paths, import your own files, and review alignment plots. Supplying only one event file with time_seconds records an explicit shared-clock assumption.

Independent execution: importing files does not silently align them. Run the synchronization subanalysis to fit the clock map, inspect residuals and missing pulses, then approve the unified trial table used by raster, PSTH, statistics, and decoding.
