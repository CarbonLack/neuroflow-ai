NeuroFlow 逐页操作手册

NeuroFlow page-by-page operation manual

本手册不只说明“软件有什么”，而是解释每一步为什么存在、按钮会执行什么、 参数改变会产生什么结果、什么现象说明输入或方法可能有问题，以及结果应如何进入下一步。

This manual explains why each stage exists, what controls execute, how parameters change outputs, which signs indicate problems, and how evidence moves downstream.

步骤状态的含义

等待运行 / pending
节点尚未用当前项目和参数生成结果。页面可显示输入预览，但不能把预览当作完成结果。
运行中 / running
后台任务正在计算。可查看固定进度，但不要移动源文件或强制关闭程序。
已完成 / completed

警告 / warning
计算可能完成，但输入质量、统计假设或兼容性存在需要人工处理的问题。
失败 / failed

跳过 / skipped

01 数据与项目

目的

确认数据结构、来源、单位、探针、事件和可用流程边界。这里的错误会传播到所有后续步骤，因此“图能画出来”不能证明导入正确。

页面元素代表什么操作通过标准
数据源simulated、binary、device、IBL/NWB 或 sorting output核对来源，不依赖项目名字判断与实际文件层级一致
通道原始连续记录的并行通道数与设备/探针元数据核对波形没有周期错位或异常重复
时长样本数 ÷ 采样率，或 processed spikes 的最大时间与实验日志核对数量级和 session 时长一致
Unit当前激活 sorting 结果中的候选 Unit 数只在导入/运行 sorting 后出现不把数量本身当作质量
原始多通道波形指定时间窗与通道组的电压缩放、平移、逐通道查看通道结构和量纲合理，无明显解码错误
模拟 ground-truth 计数模拟器预先知道的真实 spike 数只用于模拟验证真实数据页不应出现虚构 ground truth

必须完成的检查

  • 采样率来自设备配置，不是凭经验填写。
  • 二进制 dtype、通道数和交错顺序已经用短波形验证。
  • 电压单位是 ADC count 还是 μV 已明确，scale 有来源。
  • 探针几何与 channel ID 的映射存在，坏通道没有被错误当作几何缺失。
  • 事件时间单位是秒、毫秒、采样点还是帧号已经明确。
  • 公开/processed 数据缺少原始电压时，原始质控和 sorting 被明确标记不可用。

五类入口、字段与 CSV 样例见 数据入口完整指南。

02 原始质控

问题：这段连续电压是否值得进入预处理和 sorting？质控应先描述问题，再决定是否排除或修复。

图/指标计算内容如何阅读常见行动
多通道波形短时间窗原始电压，通道垂直错开看单通道噪声、共同伪迹、饱和、断线和 spike 样波形改变起始时间/窗口/通道组反复抽查
通道 RMS每通道均方根振幅远高于中位数提示高噪声；极低可能为死通道标记候选坏通道，回到波形和频谱找证据
通道×频率功率Welch PSD 的通道频谱矩阵窄带竖线提示工频/设备噪声；宽频异常提示接触或伪迹定位是单通道、局部通道组还是全局问题
50 Hz 比值50 Hz 功率相对 45–55 Hz 邻域基线比值高说明窄带峰明显，不等于必须 notch先检查接地/参考；对分析副本处理
饱和/clip接近 int16 极限的样本比例连续平台比单个极值更可疑标注区间并评估能否排除，不尝试“还原”丢失电压
质量随时间多个时间窗的通道 RMS突变提示插拔/伪迹，缓慢趋势提示漂移或阻抗变化定位时间段并与行为/实验日志对照

为什么每张小图都要能单独看

全局质量分数只是摘要。用户应先选择 panel，再单独放大、缩放到异常通道/频率/时间， 点击元素读取数值，必要时单独保存证据。运行当前节点会重新计算全部 QC 指标； 浏览、放大或编辑颜色不会重新计算。

坏通道判断不应只用单阈值。高 RMS 可能来自真实大振幅信号或全局伪迹； 低 RMS 可能来自安静脑区或断线。至少联合波形、频谱、邻近通道、时间稳定性和探针位置。

03 预处理

问题：为 AP/sorting 与 LFP 两类不同目标建立透明、可预览、不可重复误用的处理分支。

raw broadband ├─ AP/sorting: high-pass or band-pass → reference → sorter-specific steps
└─ LFP: low-pass/band-pass → artifact policy → downsample
步骤默认预览改变参数的影响检查
AP band-pass300–6000 Hz（上限受 Nyquist 限制）低截止升高会减少慢成分也可能改变宽 spike；高截止过低会钝化波形处理前后波形、峰值与噪声，不只看“更干净”
common median reference每时刻减去通道中位数抑制共同噪声；坏通道未排除会污染参考比较单通道和空间邻域；确认探针结构适合全局/分组参考
LFP band-pass1–300 Hz决定保留节律和慢漂移范围检查边缘、刺激伪迹和频率响应
LFP downsample约 1 kHz降低数据量；必须先低通防止混叠目标采样率需高于最高保留频率两倍且留过渡带
预览起点/时长只读短窗口不改变实际处理参数，只决定检查片段至少看安静期、行为期和异常期

防重复处理

  • 若 sorter 内部会 whitening，不在外部再次 whitening，除非方法明确要求并记录。
  • Neuropixels 相位偏移校正需要设备元数据支持，并应在参考前按工具建议处理。
  • notch 不应成为“看到 50 Hz 就无脑添加”的固定步骤；先判断对目标频段和相位分析的影响。
  • 预览从不覆盖原始数据；正式派生数据应保存参数和来源哈希。

方法接口参考 SpikeInterface preprocessing。

04 Spike sorting

问题：检测 spike 并将其分配到候选 Unit，同时保留所选 sorter、版本、参数、运行环境、日志、原生输出和统一结果。

Sorter 表格

列含义如何操作不能误解

其他适配 sorter通过统一接口持续扩展是否真实安装、许可证、系统/容器兼容保存原生输出并转换到统一秒制接口

Kilosort 运行后不应隐藏的诊断

  • 运行阶段和日志尾部：确认加载、预处理、检测、聚类、保存分别是否完成。
  • drift map / spike depth-time-amplitude：查看时间漂移、深度层和振幅变化。
  • 模板波形与空间 footprint：检查局部形状、主通道和传播范围。
  • amplitude over time：检查 Unit 是否稳定存在、是否突然消失或被拆分。
  • 模板相似度和可能重复 Unit：避免把同一神经元计数两次。
  • ACG/ISI 与 contamination：sorting 输出后进入 Unit QC，不把自动 cluster 直接称为单神经元。

Kilosort 参数与输出分别见 parameter guide、 exported files； 多 sorter 统一与比较参考 SpikeInterface comparison。

05 Unit 质控

问题：哪些候选 cluster 可以进入当前科学问题？阈值是筛选规则，不是生物学真理，且不能只依赖单一指标。

指标/图定义常见解释局限
Firing ratespike 数 ÷ 有效记录时长极低放电率难以稳定估计响应低率神经元可能真实存在，阈值需按任务和时长
ISI violation短于不应期阈值的间隔比例高值提示污染、多单元混合或重复检测受放电率、漏检和 burst 影响
SNR波形幅度相对噪声尺度低值提示分离证据弱定义和预处理依赖工具，不同项目不可盲目横比
Mean waveform对齐 spike 片段平均看形状、极性、主通道与局部空间分布平均会隐藏随时间变化和混合波形
ACG同一 Unit spike 时间差直方图零附近低谷支持不应期，峰结构反映节律/burst边界、bin 和时长影响形状
Amplitude stability抽样 spike 振幅随时间持续趋势/分段变化提示漂移或 Unit 丢失自动增益、行为状态也可改变振幅
  1. 先选一个 Unit，在所有诊断 panel 中确认当前查看的是同一 Unit。
  2. 用散点概览识别低 SNR、高 ISI、极端放电率候选，并点击查看数值。
  3. 放大 waveform、ACG 和 amplitude-time，不以单个阈值自动判定。
  4. 写入 good / MUA / noise / uncertain 与理由，保留人工修改人和时间。
  5. 筛选后重新确认条件 trial 数、统计样本单位和解码特征维度。

07 行为分析

问题：在解释神经活动前，确认 trial 数、类别平衡、缺失、表现和反应时能够支持比较。

结果阅读方式后续影响常见错误
条件计数每个 condition 的 trial 数决定统计功效和分类平衡把多个事件行误当多个独立 trial
反应时分布response - stimulus 或任务定义的时间差可分层、协变量或排除极端值事后按结果挑阈值且不记录
心理测量曲线选择概率随刺激强度检查任务执行与刺激-行为关系将 trial 计数不足的点与高样本点等权解释
缺失/排除每条排除规则与数量决定神经分析使用哪些 trial静默删除错误 trial，导致复现困难
正确率/反馈任务定义下表现可比较正确/错误或学习阶段把选择方向和正确性混成同一 condition
  • 样本单位明确为 trial，且一个 trial 的多事件不会重复计数。
  • 类别不平衡在统计和机器学习中分别处理，不通过简单复制小类制造独立样本。
  • 行为排除规则在看神经结果前尽量预先定义。
  • 跨 session/动物汇总时保留层级 ID，不把全部 trial 当作同一独立总体。

09 统计检验

问题：先定义样本单位、配对关系和层级结构，再选择检验；图不是统计证据本身。

方法回答的问题主要假设/条件NeuroFlow 输出
paired t-test同一 trial/Unit 的前后均值差差值近似正态，样本配对正确t、p、mean difference、Cohen's dz
Wilcoxon signed-rank配对差值的秩位置变化配对、差值分布可解释；大量 ties 需注意W、p、rank-biserial
配对符号翻转置换均值差相对于符号置换零分布零假设下差值符号可交换permutation p，作为当前主要单 Unit 检验
bootstrap CI效应量不确定性重采样单位与推断单位一致95% percentile CI
Welch / Mann-Whitney两个独立条件的响应差trial 独立；前者均值、后者分布秩statistic、p、Hedges' g
ANOVA / Kruskal多组总体差异独立性；ANOVA 还关注残差/方差p；显著后仍需预设 post-hoc
mixed effects条件效应同时建模 Unit/动物/session 层级随机效应结构、收敛和足够组数公式、系数、p、收敛与 warning
FDR/Holm/Bonferroni控制多重比较错误校正集合必须预先定义q/adjusted p 与显著 Unit 数
真实数据可能出现全零或全相同样本。NeuroFlow 将这类检验标为 not_testable_all_values_identical，而不是让 Kruskal 或相关函数中断整页， 也不会把未定义统计量悄悄当作显著。
  • n 是动物、session、Unit 还是 trial 已在图和 Methods 中写明。
  • 嵌套于同一动物的数百 Unit 不被自动当作数百个独立生物学重复。
  • 报告效应量和置信区间，不只报告 p 值。
  • 多重比较集合、方法和 alpha 已记录。
  • 常量、缺失、ties、方差为零和模型不收敛有明确状态。

10 机器学习

问题：神经特征能否在严格的数据划分下预测条件或连续行为，而不是在泄漏的训练/测试样本中追求高准确率。

控件/方法用途关键选择质量检查
分类模型Logistic、SVM、Random Forest、XGBoost 等预测离散条件复杂度、标准化、类别权重balanced accuracy、confusion matrix、per-class recall
回归模型预测反应时、位置、连续行为变量损失、正则化、目标变换R²、MAE、残差和跨 session 泛化
PCA可视化主要群体变异方向样本×特征定义、标准化解释方差，不把 PC 自动解释为生物过程
聚类探索 Unit/trial 的无监督结构距离、维数、cluster 数/密度稳定性和外部变量验证
交叉验证估计未见数据表现按 trial/session/animal 分组训练与测试不得共享同一泄漏来源
置换检验比较真实标签表现与 shuffle 零分布置换单位必须保持数据层级报告置换次数、p 和零分布
特征重要性描述模型依赖哪些输入系数、permutation importance、树重要性相关特征会分摊/替代，不直接等于因果编码

运行前必须回答

  1. 一行样本是什么：trial、时间窗、session 还是动物？
  2. 特征是在标签未知的情况下提取的吗？是否用全数据选择了“最佳 Unit/时间窗”？
  3. 同一 session 或动物是否同时进入训练与测试？若是，为什么不会泄漏？
  4. 类别是否不平衡，基线和 balanced metric 是什么？
  5. 置换是打乱 trial 标签还是错误地打乱单个时间 bin？
  6. 最终模型是否在独立 session/动物上验证？

公开 Buzsáki 单会话上的高 balanced accuracy 只能证明这份会话和当前特征可被分类，不能证明跨动物泛化，也不能自动写成“神经元编码奖励类型”。
