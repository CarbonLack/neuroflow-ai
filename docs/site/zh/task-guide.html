先用示例熟悉操作

没有自己的数据也可以开始。建议先打开 8 通道微丝教学示例。

先准备好

教学模拟在本机生成；已验证公开项目首次打开可能需要联网下载。

  1. 打开示例库

    选择“文件 → 示例项目…”，或点击首页“示例项目”。

  2. 选择一套数据

    选择教学模拟行，点击“打开所选示例”。公开项目也在同一个列表里，可根据内容和可用状态选择。

  3. 完成第一次分析

    先查看“原始质控”，再到“Spike sorting”选择环境可用的 sorter，运行本步骤。每次完成后看图和结果再继续。

完成检查

左侧流程可直接切换。“下一步”切换页面，“运行”才会计算。

保存位置

示例会成为普通项目；从“文件 → 打开项目文件夹”查看保存位置。

示例没有原始波形

部分公开项目只有已排序 Units 和行为数据。可从 Unit 质控和下游分析开始。

导入自己的原始记录

从采集文件或通用二进制建立项目，导入后先核对记录信息和波形。

先准备好

原始文件、采样率、通道数、数据类型、增益和探针信息。设备文件通常自带一部分信息。

  1. 选择数据入口

    点击首页“新建项目”，选择记录系统文件或通用二进制。已打开的空项目可用“数据与项目 → 导入我的电生理数据”。

  2. 核对读取参数

    设备记录选对应读取器。通用 .bin/.dat 核对采样率、通道数、dtype、μV/bit；即使从 params.py 自动带入也要确认。Open Ephys 未指定数据流时会尝试选择 AP。

  3. 查看第一次读取结果

    创建后检查“数据与项目”的来源、时长和通道数，移动波形时间窗，确认不同通道的信号正常。随后进入“原始质控”。

完成检查

用采集软件的记录信息核对参数；采样率或通道数错误会让时间和波形一起出错。

保存位置

项目保存来源索引、读取参数和可用缓存。位置见“文件 → 打开项目文件夹”。

Open Ephys 提示多个数据流

在导入窗口填写所需 stream_id；AP 用于 spike 分析，LFP 数据流用于低频分析。

接着分析已有排序结果

已有 Kilosort/Phy 或 Offline Sorter 结果，可以直接进入 Unit 质控。

先准备好

Kilosort/Phy 结果文件夹及原采样率，或 .nex5 文件。事件分析还需要事件时间。

  1. 选择结果格式

    在导入窗口选择“已有 sorting 结果”或“Offline Sorter / NeuroExplorer 结果”。

  2. 核对文件与时间

    Kilosort/Phy 选择包含 spike_times.npy 和 cluster 分配的文件夹。NEX5 核对“时间对齐方式”，仅在有实验依据时使用结束时间对齐或手动偏移。

  3. 检查候选 Unit

    导入完成后到“Unit 质控”运行本步骤。若要对比同一记录的不同结果，先打开对应原始记录项目，再向该项目导入结果。

完成检查

Unit 数和记录时长应接近原软件显示值。仅有 spike 时间时，原始信号和 LFP 分析可能不可用。

保存位置

项目保留标准化 spike 时间、来源和可用波形信息，可继续复核、事件分析和导出。

导入后时长差很多

先核对原采样率及 NEX5 时间偏移。不要为配合一张图而随意修改采样率。

打开上次保存的项目

用项目清单继续上次的工作，包括已有结果和最后保存的页面。

先准备好

项目文件夹中的 neuroflow_project.json，以及该项目依赖的原始数据或缓存。

  1. 打开项目清单

    按 Ctrl+O，或选择“文件 → 打开／导入项目…”，找到 neuroflow_project.json。

  2. 确认恢复内容

    查看项目名称、来源路径和左侧步骤状态。已完成的结果可直接查看；只运行需要更新的步骤。

  3. 保存这次工作

    按 Ctrl+S。通过“文件 → 打开项目文件夹”检查说明、日志、结果和导出文件。

完成检查

项目清单记录文件位置；单独复制这个 JSON 文件不会复制全部数据。

保存位置

沿用原项目文件夹；最后保存的工作流页面记录在项目中。

换电脑后找不到原始记录

查看 inputs/source_index.json 中的来源。恢复对应数据路径；重新分析前确认所需文件可以读取。

检查原始波形和坏通道

用波形、功率图和时间线定位噪声，决定后续需要关注哪些通道与时段。

先准备好

包含可读取原始电压的项目。

  1. 运行原始质控

    打开“原始质控”，点击“运行当前所选分析”。等底部状态显示完成。

  2. 切换诊断视图

    在标题旁的下拉框依次查看“质控指标总览”“通道 × 频率功率图”和“记录期间质量时间线”。

  3. 返回波形核实

    切回“多通道原始波形”，调整时间窗和通道范围，核实提示中的噪声、饱和或异常时段。把确认事项写入项目的人工实验笔记。

完成检查

质量分是汇总提示。注意检查实际评估时段，不能由一个分数认定整段记录可用。

保存位置

质控结果随项目保存；日志和人工笔记位于 logs 文件夹。

页面提示没有原始电压

只有已排序 Units 的项目可直接做 Unit 质控。若需要原始质控，请导入对应采集记录。

方法参考

查看 AP 与 LFP 预处理预览

检查短片段处理前后变化，并查看实际记录的处理链。

先准备好

原始电压和已核实的采集信息；先完成原始质控。

  1. 生成预览

    进入“预处理”，点击“运行当前所选分析”。这里生成短片段预览。

  2. 按分析对象查看

    切换“AP / sorting 分支”或“LFP 分支”，对比波形与频谱。

  3. 核对处理链

    查看“可审计处理链与安全检查”。到 sorting 页后，再核对所选 sorter 的输入说明和内部处理。

完成检查

本页预览不会把已白化数据再交给 Kilosort4。当前预览使用的参数以处理链记录为准。

保存位置

预览结果和处理参数保存到项目，可重新打开查看。

想修改滤波或参考参数

先查看处理链。当前桌面预览并非任意处理链编辑器；高级参数可由 Python 接口设置，并保留实际参数记录。

方法参考

选择 sorter 并运行

先看环境和探针适用性，再运行一个 sorter；结果可保留用于后续比较。

先准备好

原始电压、正确的采样率和通道几何，以及表中显示可用的 sorter 环境。

  1. 确认 sorter 可用

    打开“Spike sorting”，查看表中的“环境”“硬件”“适用记录”。缺少依赖时打开“编辑 → Sorter 管理…”。

  2. 选择并核对参数

    点击要运行的 sorter 行。Kilosort4 可查看预设、batch_size、漂移块和阈值；MountainSort5 可选择方案、检测阈值和训练时长。

  3. 运行并看诊断

    点击底部运行按钮，确认对话框中的 sorter。完成后用“运行后诊断视图”查看输出，并到“Unit 质控”检查候选 Units。

完成检查

Simple 适合快速检查流程；正式分析需要结合记录类型选择方法并复核 Units。

保存位置

原生结果与日志位于 results 下对应 sorter 的文件夹，统一结果随项目保存。

运行失败或显存不足

先读失败提示和日志。Kilosort 可检查 GPU 环境和 batch_size；也可选择表中可用的 CPU sorter 验证输入。

方法参考

横向比较两个 sorting 结果

并排查看 Unit 数、spike 数、独有 Unit 和匹配一致度，定位方法差异。

先准备好

同一项目内至少两份 sorting 结果；比较前核对来源记录、通道和时间范围。

  1. 准备第二份结果

    在同一原始记录项目运行另一个 sorter，或导入该记录的外部排序结果。

  2. 打开比较视图

    在“Spike sorting”的“运行后诊断视图”中选择比较视图，然后选择要比较的结果对。

  3. 查看差异并复核

    先看匹配 Unit 和一致度，再看各自独有 Unit。回到 sorter 列表选择要查看的结果，进入 Unit 质控核实波形和稳定性。

完成检查

相同输出时窗不等于相同训练时长。真实记录没有真值时，一致度不能解释为准确率。

保存位置

results/sorting_comparison 保存 sorter_summary.csv、pairwise_summary.csv 和比较说明。

比较列表为空

确认两份结果都保存在当前项目。来自不同记录的结果不应混放后直接比较。

逐个复核 Unit 并保存判断

将自动指标与波形、ISI 和稳定性一起查看，保存自己的复核结论。

先准备好

已运行或导入 sorting 结果；波形诊断取决于导入文件中可用的信息。

  1. 计算 Unit 指标

    进入“Unit 质控”并运行本步骤。标题旁可切换“Unit 指标总览”或某个 Unit 的波形/ACG/ISI/稳定性。

  2. 打开人工复核

    点击“打开人工 Unit 复核工作台”。左侧选择 Unit，中间查看诊断，右侧填写“人工分类”“置信度”和“复核人”。

  3. 记录判断依据

    勾选已检查的证据，写入“复核备注”，点击“保存本 Unit 结论”，然后查看下一个 Unit。

完成检查

分类和备注会保存；当前工作台不提供 cluster 合并或拆分操作。缺失指标不能作为通过证据。

保存位置

复核记录随项目保存；导出时可保留人工结论及其依据。

人工复核按钮不可用

先确认有 sorting 结果，再运行 Unit 质控生成指标。

方法参考

把行为事件对齐到电生理时间

导入行为文件和同步脉冲，核对时间换算后再做事件响应。

先准备好

通用事件 CSV 或 MED-PC C/D 数组；如使用独立行为时钟，还需要对应 TTL。

  1. 导入行为与 TTL

    进入“事件同步”，点击“导入 / 替换行为与 TTL”，选择格式和文件。Open Ephys 可读取采集系统数字输入。

  2. 核对时钟来源

    CSV 核对时间单位；MED-PC 核对行为同步事件码和采集系统 TTL 通道。保存后运行当前步骤。

  3. 检查对齐结果

    查看脉冲数、匹配数量、时间偏移、漂移和残差。检查事件是否落在记录范围内。

完成检查

缺脉冲、重复脉冲或错误通道会影响按顺序配对的结果。先修正事件来源再解释神经活动。

保存位置

导入配置、对齐记录、事件和可定义的 trial 随项目保存。

有事件但没有 trial

事件列表不一定包含明确 trial 边界。先检查行为文件是否提供 trial 定义；可用事件时间不代表行为表现指标都可计算。

检查行为与有效 trial

先确认行为数据是否完整，再判断哪些条件适合做神经比较。

先准备好

已导入行为事件；反应时、选择和心理测量分析需要对应 trial 字段。

  1. 生成行为摘要

    打开“行为分析”，运行本步骤。查看当前事件数、trial 数和行为图。

  2. 核对条件和样本数

    查看各条件的 trial 数、可用反应时和选择。样本太少或字段缺失时，先检查原始行为文件。

  3. 再选择神经分析

    确认需要对齐的事件和要比较的条件后，进入“神经活动”。

完成检查

仅导入事件时间不会自动产生实验选择、正确率或反应时。空白面板应先检查输入字段。

保存位置

行为摘要保存在项目中；运行“论文与复现”后可查看相关导出。

反应时或心理测量图为空

查看 trial 定义与字段是否齐全。若仅有离散事件，可先使用事件相关分析。

选择神经分析与事件响应

同一个页面提供多种分析，用标题旁的下拉框选择你这次要回答的问题。

先准备好

Spike 分析需要 Units；事件响应需要事件时间；LFP 与 spike-field 分析需要可用电压。

  1. 选择分析对象

    查看单 Unit 事件响应选“事件 · Unit …”；比较 spike train 选统计或关系；群体、精细时序和 LFP 各有独立选项。

  2. 运行所选分析

    点击“运行当前所选分析”。群体动态和精细时序会打开设置窗口；其他选项使用当前项目和方法的参数。

  3. 核对图和表

    事件响应查看 Raster 和 PSTH，核对横轴事件零点与有效 trial 数。切换选项查看对应结果，用图形工具缩放。

完成检查

页面下拉框同时承担分析选择和结果切换；更换选项后看底部“当前”说明，再决定是否运行。

保存位置

已完成分析保存在项目中；图表可通过“论文与复现”导出。

页面仍显示待运行

确认该类别已经运行且输入齐全。完成事件响应不会自动完成 LFP、群体或精细时序分析。

比较群体响应与 PCA 轨迹

按事件或条件查看多个 Units 的热图、单 trial 响应和群体轨迹。

先准备好

可用 Units 和事件；条件比较需要已有条件标签。

  1. 打开群体分析

    在“神经活动”选择任意“群体动态”选项，点击“运行当前所选分析”。

  2. 设置本次范围

    在弹出的设置窗口核对事件、Unit 范围、分析窗口、分箱和基线。排序规则决定热图行的排列。

  3. 查看四种结果

    运行后切换“排序热图”“单 trial”“条件比较”和“PCA 轨迹”，确认各视图使用的条件与时间范围一致。

完成检查

标准化后的热图颜色表示相对变化；查看图例，避免把它直接解释为 Hz。

保存位置

群体分析结果及运行参数保存在项目；可单独保存需要的图面板。

部分事件被排除

检查事件靠近记录首尾时，分析窗口是否超出记录范围；同时核对事件和 Unit 筛选。

检查毫秒级时序关系

比较 Unit 对的 CCG 与抖动校正结果，再看空间或跨区域分布。

先准备好

多个可用 Units；空间分析还需要可信通道位置和脑区标记。

  1. 选择精细时序

    在“神经活动”选择“精细时序 · CCG 与抖动校正”，点击运行。

  2. 核对成对比较设置

    在设置窗口确认 Unit 对、时间范围、分箱、抖动与显著性设置。Units 很多时先缩小比较范围。

  3. 检查单对再看网络

    先看单对 CCG 和校正结果，再切换“空间/跨区域网络”及“距离与延迟统计”。

完成检查

时序关系会受到共同输入和放电率变化影响；显著 CCG 不能单独确认突触连接。

保存位置

Unit 对结果、运行设置和网络统计随项目保存。

距离或脑区信息缺失

先核对导入的探针几何和脑区标记；信息不足时仍可检查时间关系，但不能解释空间结果。

查看条件差异与统计依据

将条件差异、效应量和样本结构一起查看，确认检验适合你的实验。

先准备好

已完成相应神经分析，具有可比较的条件或配对响应。

  1. 运行统计套件

    进入“统计检验”，点击“运行当前所选分析”。

  2. 先看研究设计

    切换“样本层级与检验决策”，核对样本是 trial、Unit、session 还是动物，以及是否属于配对测量。

  3. 查看效应与检验

    用“条件检验与效应量”和“效应量与多重比较”检查效应方向、置信区间和校正值；有需要再看分布或相位检验。

完成检查

本页下拉框切换统计结果视图，不是所有检验参数的编辑器。多只动物或多 session 的设计需要核实输入层级。

保存位置

统计结果随项目保存；完整导出提供相关表格和方法记录。

检验无法计算

检查有效样本量、条件是否齐全、是否有常数列或缺失值。查看具体提示后处理输入。

运行分类或回归模型

比较神经特征能否预测任务变量，同时检查交叉验证和基线。

先准备好

有效 trial、神经特征及要预测的分类标签或连续行为变量。

  1. 选择任务和模型

    进入“机器学习”，在标题旁选择“分类 · …”或“回归 · …”。分类预测类别，回归预测连续数值。

  2. 运行当前模型

    点击“运行当前所选分析”，核对确认窗口中的模型名称。

  3. 核对验证结果

    分类查看混淆矩阵、交叉验证和置换基线；回归查看预测与实测及误差。比较模型时使用相同数据范围。

完成检查

结果中的实际特征、样本数和拆分方式需要核对。PCA 可视化和较高分数本身都不能证明因果关系。

保存位置

模型评估与参数随项目保存，可从“论文与复现”导出。

样本或标签不足

返回行为分析核对有效 trial 与条件数量。不要通过复制 trial 来凑够交叉验证样本。

保存项目、图和实验记录

保存便于下次继续；导出提供便于查阅、编辑和交付的图表与记录。

先准备好

一个已打开的项目；要导出的分析应先完成。

  1. 保存当前项目

    按 Ctrl+S 或选择“文件 → 保存项目”。保存成功后，可用项目清单继续工作。

  2. 整理图形输出

    在分析页用“图形设置”调整图；需要单幅图时使用面板选择和保存按钮。完整导出请进入“论文与复现”运行本步骤。

  3. 找到成果和日志

    选择“文件 → 打开项目文件夹”。看 00_README_项目说明.md；图和表在 exports，分析结果在 results，实验日志与人工笔记在 logs。

完成检查

交付前打开导出的图核对标题、坐标、单位和统计标记。项目依赖外部原始数据时，备份也要包括这些来源。

保存位置

neuroflow_project.json、inputs、config、logs、cache、derived、results 和 exports 组成项目记录。

只找到 JSON，没有图

“保存项目”与“论文与复现”导出是两项操作。先完成分析，再运行导出并检查 exports。

调整三栏、AI 助手与提示

按窗口大小分配流程、图表和 AI 的空间，随时收起或恢复。

先准备好

打开项目后即可调整三栏；使用在线 AI 需要在 AI 设置中配置服务。

  1. 调整三栏宽度

    拖动栏间分隔线。按 Ctrl+B 缩略左侧流程，按 Ctrl+J 显示或关闭右侧 AI。三栏可以同时保留。

  2. 按需要使用 AI

    在右侧选择“审查项目”“建议流程”或输入问题；“设置”可选择服务。核对 AI 引用的当前项目和步骤，再采纳建议。

  3. 控制引导和布局

    按 F1 查看本步引导；在“帮助”取消“自动显示分步骤引导”可停止自动弹出。用“视图 → 恢复三栏默认布局”恢复布局。

完成检查

图表缩小时可使用图形工具缩放，或 F11 全屏。AI 建议需要结合实验记录和实际输出核对。

保存位置

分析结果仍由所选分析操作生成，AI 回复显示在右侧对话区。

找不到底部运行按钮

先收起右侧或缩略左侧，再调整窗口高度；也可从“分析”菜单运行当前所选分析。
