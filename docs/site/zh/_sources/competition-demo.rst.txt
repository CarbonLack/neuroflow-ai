决赛演示与离线保障
==================

App 的 **帮助 → 决赛演示准备** 将比赛要求转成可检查的证据清单，而不是把汇报做成
一段纯技术介绍。清单只报告实际存在的项目、分析、图件、论文排版、AI 配置、sorter 和
离线手册；缺失项保持未勾选。

推荐 5–10 分钟顺序
------------------

1. 实际问题与目标用户：导入、分选、行为对齐、解释和复现分散在多个工具中。
2. 创建或导入项目：强调源数据只读、项目可恢复、参数和中间结果可追溯。
3. 展示质控、三 sorter 横向比较和事件同步。
4. 展示 Raster/PSTH、统计证据与面向初学者的解释。
5. 展示英文主图、附图、panel 字母、图注草稿和完整产物索引。
6. 展示 AI 如何读取脱敏项目上下文、提出建议并受工具白名单约束。
7. 用真实运行记录说明效率、失败原因、修正和仍需人工复核的限制。

现场保障
--------

同时准备完整安装版、标准安装版、便携版、离线手册、已导出的模拟项目、真实项目、
截图和短录屏。现场不重新跑长时 sorter；用已保存项目展示结果，网络不可用时切到
手动模式，所有确定性分析与导出仍可运行。

点击对话框中的 **导出演示准备包** 会生成 Markdown 和 JSON，方便后续制作 PPT、
录屏脚本和最终核对表。该清单不是科学有效性认证，候选 Unit 和生物学结论仍需人工审核。
