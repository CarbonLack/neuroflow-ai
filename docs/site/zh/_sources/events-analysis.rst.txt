行为同步与事件对齐分析
======================

行为设备和电生理设备通常具有不同起点，长记录中还可能出现时钟漂移。共同 TTL 序列
提供两个时钟之间的匹配锚点。

导入和映射事件
--------------

在 **06 事件同步** 页面选择行为文件和解析器，建立数字事件码与事件名称的映射，
指定电生理 digital input 通道以及同步开始/结束码。对齐前先检查事件数。任务事件和
同步事件默认分开显示。

判断对齐质量
------------

检查匹配锚点数、未匹配脉冲、残差分布、残差随时间趋势和拟合的时钟变换。平均残差
较小仍不能抵消整段漏脉冲或非线性误差。

Raster 与 PSTH
--------------

选择事件码或条件名称、对齐窗口、bin 宽、基线窗和响应窗。软件分别筛选每个条件，
并保存纳入数量和排除原因。

Raster 每行对应一个纳入事件，颜色表示条件。PSTH 显示条件均值和标准误，淡色区域
标出实际基线窗和响应窗。群体热图采用基线 z 分数和发散色带。

单 trial 与群体动态
---------------------

在 **08 神经活动** 页面选择群体动态视图后，运行前可以明确选择事件条件、
脑区 Unit 范围、时间窗、bin 宽、高斯平滑 :math:`\sigma`、基线方式和 Unit 排序。
基线可选“各 Unit 跨 trial 统一”或“每个 trial 单独”；排序可选峰值时间、PCA 载荷或
可选 Rastermap 后端。结果可在排序热图、单 trial、条件比较和 PCA 轨迹之间切换。

对可变反应时任务，Python API 还接受每个 trial 的有效起止时间，避免将 trial 外时段
当成零放电。连续行为回归以完整 trial 为训练/测试分割单位，可设置神经—行为时滞和
重复的神经元数量扫描。

精细时序关系
----------------

精细时序模块不默认解释为解剖连接。用户可选计数型、参考放电率归一化或
trial/放电率/时滞边缘校正 CCG；选择固定窗或中心抖动、侧翼标准差或经验 P 值、
FDR/Bonferroni/不校正，以及同区、跨区和距离限制。运行前界面会显示候选对数和替代
CCG 计算量。

必须检查
--------

* 解释左右、成功/失败曲线前，核对事件码含义。
* 查看两个条件的事件数量和排除原因。
* 先检查单 Unit，再使用群体平均。
* 确认基线窗没有覆盖响应期。
* 多 Unit 或多时间点检验时，核对 FDR 输入集合和校正方式。

图中的“事件序号”只表示纳入事件的顺序。只有项目已建立有效 trial 表时，页面才会
使用 trial 名称。
