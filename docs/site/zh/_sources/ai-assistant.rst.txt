受控 AI 助手
============

AI 助手位于分析工作区右侧，可以收起。它接收本地确定性代码生成的小型结构化项目
摘要，原始电压数组不会进入模型请求。

三种模式
--------

手动模式
   不发送模型请求，全部科学控件保持可用。

助手模式
   模型解释当前页面、参数、警告和后续选择，无执行权限。

协作模式
   模型可以提出白名单工具调用。NeuroEphys AI 检查 JSON 结构、前置条件、依赖、
   工作流顺序和风险，随后弹窗，由用户决定是否执行。

模型 Provider
-------------

当前 Provider 层支持 DeepSeek、OpenAI Responses、OpenAI 兼容服务、机构托管
harness、实验室/私有兼容服务和本机 Ollama。服务地址、模型、超时、重试、流式输出和推理选项均可配置。API 密钥保存在
操作系统凭据区或当前会话中，不写入项目、日志、导出文件和 Git。

本机已部署 DeepSeek Harness 时，点击 **读取本机 DeepSeek Harness 配置**。应用只读取
Provider、``/v1`` 地址、模型列表和环境变量名，不读取 Harness 凭据文件。内网 HTTP
必须对该 Provider 显式启用，然后用“检测服务状态”验证模型列表和延迟。

这是 App 内置的 OpenAI-compatible Provider 适配，不是用界面自动化操作 Harness 网页。
Harness 只负责模型访问；NeuroEphys AI 负责生成项目上下文、校验工具和要求用户确认。

发送内容预览
------------

在线请求前，点击 **预览云端数据** 可以查看准备发送的字段类别。用户可以删除可选
字段或取消请求。本地路径、原始电压、大型数组和 API 密钥会被排除。

科学解释结构
------------

结果说明分为：已观察结果、统计证据、可考虑的生物学解释、当前证据无法支持的结论、
数据和方法限制、建议增加的验证。模型输出用于辅助判断。工具名称、参数和工作流节点
必须通过本地 JSON Schema 与规则检查。

上下文协议使用版本号。每次请求都包含工作流顺序、当前节点、已有输入、分析摘要、
失败/跳过节点、输出清单和 UI 位置；新增模块只要把结构化结果注册到项目摘要与工具白名单，
AI 即可读取，同时仍不能直接读取原始电压、任意本地文件或调用未注册功能。

本机 Ollama
-----------

单独启动 Ollama，下载兼容模型，在设置中选择本机 Provider。默认兼容地址为
``http://127.0.0.1:11434/v1``，该模式不会向云端发送项目摘要。

.. warning::

   配置 Provider 不代表已经授权发送项目内容。每次在线请求都会显示发送字段类别，
   并等待用户确认。
