NeuroFlow 操作手册

安装与运行

桌面程序、科学计算环境、sorter 后端和项目数据彼此分离，单个工具安装失败不会阻止 NeuroFlow 打开。

系统要求

  1. 界面支持 Windows 10/11、macOS 或 Linux。
  2. 磁盘需要同时容纳原始数据、标准缓存、sorter 输出和导出文件。
  3. Kilosort4 推荐 NVIDIA GPU；CPU sorter 作为独立备选，不是假装执行 Kilosort。

桌面软件安装

  1. 安装或解压 NeuroFlow 发行版。
  2. 直接启动 NeuroFlow，不要求用户先打开 Python 终端。
  3. 在“Sorter 管理”中查看真实后端、版本、硬件要求和适用探针。

项目存储

  1. 原始数据保持只读；通用二进制可只建立索引，也可复制到项目。
  2. 项目包含 neuroflow_project.json、派生结果、sorter 原生目录、导出和审计记录。
  3. 使用索引时保持源路径稳定；需要独立归档时复制原始数据。

外部 sorter 环境

  1. 只有通过实际环境检测的 sorter 才显示“可运行”。
  2. Kilosort4 使用其 Python/GPU 环境；其他 sorter 可使用 CPU、容器或独立环境。
  3. NeuroFlow 保存真实错误，绝不静默换用另一个 sorter。
