真实数据验证

本章公开软件验证的范围、参数和科学限制。授权原始数据、身份信息、实验室目录和 逐动物结果均保留在本地，不随仓库和安装包发布。

验证目的

真实数据验证回答以下工程问题：

  • Open Ephys Legacy 记录能否从图形界面直接读取；

  • 用户选择的通道、时间范围、采集设置和电极说明能否写入项目；

  • 长记录能否分段读取，避免一次性占用数十 GiB 内存；

  • 多种 sorter 的原生结果能否保留，并转换到统一的秒级 spike 接口；

  • MED-PC 事件和数字输入同步脉冲能否建立同一时间轴；

  • 项目保存、关闭和重新打开后，能否继续下游分析；

  • 图、表、统计、模型结果和运行日志能否追溯到输入与参数。

数据和采集边界

本次授权记录来自 32 根独立排列的自制微丝，记录系统为 Open Ephys Legacy。 快速回归使用每段至少 1800 秒的数据，长记录回归覆盖 7497.489 秒。

采集时已在线完成 250--8000 Hz 滤波和参考处理。低频成分无法从这批保存数据中 恢复。因此项目会阻止 LFP、低频功率谱、LFP coherence 和 spike-field coupling。 AP 波段的高频数据不能作为 LFP 的替代品。

长记录 Kilosort4 恢复结果包含 12 个候选 Unit 和 2,195,626 个 spike。所有数量均为 算法候选，不代表经过人工认证的单神经元数量。人工复核仍需同时查看波形、不应期、 振幅稳定性、漂移、重复和拆分风险。不同 sorter 的数量差异用于暴露算法假设与 阈值影响，不能直接用来判断哪个结果更准确。

外部 Offline Sorter 结果

数据提供者给出的两个 .nex5 文件通过官方 nex5file Python API 只读导入。 文件名筛选限定为同一次 SW#1 记录；LO 文件含 5 个候选 Unit，MO 文件含 3 个， 合计 8 个候选 Unit 和 273,358 个 spike。程序保留外部名称、通道号、LO/MO 分组、 波形摘要和源文件索引，同时转换成统一的秒时间 + Unit 编号接口。

NEX5 文档结束时间为 7653.4056 秒，原始记录长度为 7497.4891 秒。完整记录入口使用 结束时间对齐，推断偏移为 155.9165 秒；该推断写入来源记录，不能替代独立同步证据。 截取片段入口会拒绝自动结束对齐，要求用户提供人工或同步推导的偏移。

全时长项目把 8 个外部候选 Unit 与 12 个 Kilosort4 候选 Unit 进行一对一时间比较， 容差为 0.5 ms，滞后搜索范围为 ±2 ms。只有 1 对达到强一致；部分外部 Unit 对 高放电率 Kilosort cluster 表现为高召回、低精确率，可能来自合并、污染或不同 Unit 定义。这个比较用于安排人工复核，不把外部结果视作 ground truth，也不能据此 判定真实神经元总数是 8 还是 12。

行为与同步

30 分钟项目解析出 4,654 个 MED-PC 事件，744 对同步锚点全部匹配。事件按 event code + event name + seconds 保存；同步脉冲独立显示，默认不与任务事件 挤在同一张计数图中。

当前实验尚未配置可泛化的 trial 定义，因此软件导出 events.csv，不会把单个 事件错误标记为 trial。左右条件分析会分别记录事件码、纳入事件数、时间窗、 baseline、每个 Unit 的矩阵形状和统计来源。

统计和解码限制

早期技术回归曾把事件码 21 和 22 作为左右条件：两类各有 67 条记录，但 67 对 时间戳逐一相同。条件审计因此判定这 134 条记录不能组成有效二分类任务。该旧流程 得到的 Logistic regression 平衡准确率 0.425 和标签置换 p=0.961 仅保留为 Bug 发现记录，不作为有效条件分析结果。

修正后的 30 分钟回归使用动作开始事件码 17 和 19，每类 34 条，共 68 条事件。 当前项目得到平衡准确率 0.7660、ROC AUC 0.803 和 50 次标签置换 p=0.0196078。事件定义虽然不再重合，这仍是单个 session、4 个候选 Unit、 低置换次数下的软件链路测试，不能支持神经编码结论。

长记录回归得到平衡准确率 0.8257 和 p=0.0196078。该结果仍属于软件链路测试： 事件定义、置换次数、层级抽样和跨动物重复尚未达到正式科学推断要求。NeuroEphys AI 在报告中保留这一限制，不把技术回归结果写成神经编码结论。

项目恢复与可追溯性

保存后重新打开项目，已验证可恢复以下内容：

  • 原始数据只读链接、通道选择和分析时间段；

  • 电极、脑区、参考、在线滤波和 LFP 阻断状态；

  • QC、sorting、Unit 指标和人工复核结构；

  • 行为事件、同步映射、统计、解码和图表设置；

  • 结构化运行日志、产物清单和 AI 项目历史。

每次运行都记录阶段、输入、参数、工具版本、开始和结束时间、输出、警告、错误与 恢复建议。授权验证的完整本地路径和逐步运行记录保存在项目 exports/documentation 目录，公开文档仅保留脱敏后的工程证据。

如何解读验证状态

文档和界面使用三种状态：

  • 真实数据已验证：在上述授权记录上实际运行并检查输出；

  • 模拟数据已验证：在包含已知 spike 和行为事件的教学项目上验证；

  • 接口已实现，尚未验证：代码和入口存在，但尚无受控数据完成回归。

后续公开版本会继续加入可合法再分发的 IBL 与 DANDI 示例。公开数据结果用于验证 导入和分析链路，不等同于复现原论文结论。
