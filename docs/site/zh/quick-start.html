第一次使用：完成一个小项目

本练习使用 App 自带的 8 通道微丝教学数据。你会得到一份原始质控结果、一张图和一个 能重新打开的项目。无需自己的实验数据，也无需先配置 AI 或 GPU。

1. 打开教学示例

在首页点击 示例项目，选中类型为“教学模拟”的 8 通道微丝 示例，点击 打开所选示例。数据在本机生成；表格中的公开项目是另一类示例，首次打开需要下载。

进入工作区后，查看 01 数据与项目 中的项目名称、保存位置、通道数和记录时长。 中间应出现原始波形。如果没有出现，先查看底部状态和右侧日志，不要继续运行后面的分析。

2. 运行原始质控

在左侧选择 02 原始质控。查看页面上的分析选项，再点击底部 运行当前所选分析。也可以使用 Ctrl+Enter。

运行结束后切换诊断视图，查看噪声、饱和或通道质量的摘要，再返回原始波形视图核对。 质控分数是筛查线索；选出或排除通道需要结合波形和记录条件。

小技巧

点击“下一步”只是切换页面，不会替你运行计算。页面显示旧图或待运行说明时，先核对 底部“当前”所选分析，再检查该节点是否已经完成。

3. 保存一张图

展开 图表工具，在子图选择框选中一个面板，点击 单独放大 检查坐标轴和单位。 需要修改标题或刻度时使用 编辑子图，然后点击 保存子图，选择 PNG 或 SVG。 本次练习建议保存到项目的 exports/figures 文件夹。

使用 显示全部 返回整图。修改图表样式不会替你重新计算统计或改变分析参数。

4. 保存并重新打开

按 Ctrl+S 保存项目。点击 文件 → 打开项目文件夹，确认其中包含：

  • neuroflow_project.json：下一次继续工作的入口；

  • 00_README_项目说明.md：项目数据和各目录的说明；

  • logs/实验日志_中文.md：本次做了什么、运行到哪里；

  • exports/figures：刚才选择保存的图。

选择 视图 → 返回首页，点击 打开／导入项目，选择刚才的 neuroflow_project.json。回到原始质控页，检查项目名与质控结果能否继续显示。

完成本次练习的标志是：知道当前项目存在哪里，能够找到一张导出图，并能重新打开已有结果。

接着做一次 sorting

准备继续时，先阅读 Spike sorting 与 Unit 人工复核。在 04 Spike sorting 中选择一个 环境显示可用的 sorter；微丝教学示例可以先尝试 CPU 方法。Kilosort4 的可用性取决于本机 安装与 GPU 状态，编辑 → Sorter 管理 会列出当前检测结果。

运行完成后进入 05 Unit 质控，使用 打开人工 Unit 复核工作台 查看候选。 教学数据中的已知 spike 时间可用于模拟验证，但不能代表真实实验中的准确率。

需要事件图时继续 行为同步与事件对齐分析。开始处理自己的记录时转到 新建、导入和恢复项目。
