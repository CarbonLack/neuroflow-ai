参数参考

默认值只是起点，不是通用真值。每次只改一个参数，记录原因，并比较修改前后的证据。

01 从数据结构开始

参数含义默认值推荐设置改变后的影响
采样率（Sampling rate）每秒采样点数，用于样本索引与秒之间的换算。模拟项目 30,000 Hz；设备文件读取元数据必须使用采集系统记录值；常见细胞外 spike 记录为 20–30 kHz。填小会把时间拉长、频率压低；填大会把时间压短、频率抬高。
总通道数（Channel count）二进制每个时间点包含的全部通道，包括文件中的辅助通道。模拟项目由电极模板决定按文件实际写入通道数填写，不等同于用于 sorting 的电生理通道数。错误值会重排整个文件，常出现重复、错位或斜纹波形。
数据类型（dtype）每个样本在磁盘上的存储类型。int16优先从设备元数据或导出设置读取；不要把 float32 文件当作 int16。错误 dtype 会改变帧长度和数值解释，可能仍能打开但波形完全错误。
µV / bit一个整数 ADC 步长对应的微伏数。通用导入 0.195；设备导入读取或标准化使用设备增益换算；若不确定，先保留原始计数并标记单位未知。只影响振幅单位和依赖振幅的阈值，不改变 spike 的样本位置。
复制源文件（Copy source）决定项目保存只读路径还是把原始二进制复制到项目。关闭：只读索引数据位置稳定时用索引；需要移动或长期归档项目时开启复制。复制提高可移植性但占用额外磁盘；索引节省空间但源路径失效后无法重读。

02 原始信号质控

参数含义默认值推荐设置改变后的影响
起始时间（Time start）当前预览窗口从记录的哪一秒开始。0 s先看开头，再抽查中段、结尾和任务关键事件附近。只改变显示和局部指标，不裁剪原始数据。
时间窗（Window）一次显示多少毫秒或秒。60 msspike 波形用 20–100 ms；慢伪迹和节律可用 1–10 s。短窗看波形细节，长窗看趋势，但过长会压缩尖峰。
通道范围（Channel range）同时绘制的起始通道与数量。Ch 0–11密集探针每次看 8–16 通道，并沿深度移动。通道过多会降低单通道可读性；过少可能看不到空间共同模式。
显示增益（Display gain）仅控制各通道在图中的垂直放大倍数。1.0×从 1.0× 开始，波形重叠时调低，振幅过小时调高。不改变数据和 QC 数值，只改变可视化。
工频（Line frequency）用于计算窄带工频功率的中心频率。50 Hz（中国与多数地区）按实验所在地选择 50 或 60 Hz，并同时查看谐波。选错频率会漏报工频，但不会改变原始信号。

03 预处理不是固定配方

参数含义默认值推荐设置改变后的影响
AP 频段（AP band）提供给 spike 检测或预览的通带。300–6000 Hz先使用 sorter 或领域常见默认；根据采样率和频谱证据调整。高通太高会削弱宽波形；太低会保留 LFP 漂移。低通不能超过 Nyquist。
LFP 低通（LFP low-pass）保留的最高 LFP 频率。300 Hz若只分析 <100 Hz，可设 150–250 Hz；研究高频振荡需提高并保留足够采样率。截止频率越低，尖锐瞬态越被平滑；过高会把 spike 泄漏带入 LFP。
降采样率（LFP sampling rate）滤波后 LFP 每秒保存的样本数。1,000 Hz至少为目标最高频率的 2 倍，实际通常保留 4–10 倍余量。过低会混叠或失去相位精度；过高增加内存和计算。
参考方式（Reference）从每个通道减去共同参考估计。Common median密集多通道记录可从 median 开始；稀疏 tetrode/微丝需结合分组和参考电极。average 更受极端通道影响；median 更稳健，但两者都可能移除真实共同活动。
陷波（Notch）压制 50/60 Hz 及可选谐波。默认关闭只有质控证据显示窄带污染且无法从硬件修复时开启。陷波会改变目标频率附近的振幅和相位，可能影响相位耦合分析。

04 Spike sorting 与工具选择

参数含义默认值推荐设置改变后的影响
Sorter实际执行的 spike sorting 后端。Kilosort4高密度 Neuropixels 优先评估 Kilosort4；稀疏/tetrode 可比较 CPU sorter。不同 sorter 的预处理、检测、聚类和资源需求不同，结果不可视为同一算法的参数变体。
n_chan_binKilosort 二进制文件中的总通道数，包括未用于 sorting 的通道。从项目结构读取必须与文件物理布局一致；Neuropixels 1.0 常见文件总数为 385。错误值会产生重复斜纹或错位热图，应在运行前立即停止。
batch_sizeKilosort 每个批次处理的样本数。60,000（30 kHz 时 2 s）先用默认；≤64 通道且漂移估计不稳时可增加批次包含的时间。更大批次需要更多显存/内存；过短批次用于漂移估计的 spike 更少。
nblocks漂移校正时沿探针深度分块的数量。1（刚性漂移）单 shank Neuropixels 可从 1 开始，非刚性漂移可试 5；≤64 通道或稀疏间距约 ≥50 µm 时考虑 0。0 跳过漂移校正；分块过多会在 spike 稀少时产生不稳定估计。
Th_universal / Th_learned通用模板和学习模板的 spike 检测阈值。Kilosort4 当前默认先用默认；漏检或 unit 时隐时现时每次只降低 1–2，并比较噪声和召回。阈值降低会检出更多事件，也会增加噪声和计算量。
tmin / tmax参与 sorting 的起止秒数。整段记录只有开头或结尾存在已确认伪迹时裁剪，并在审计记录写明。缩短可加快测试，但短片段结果不能代替整段稳定性评估。
duplicate_spike_ms同一 unit 中过近 spike 被判为重复并移除的窗口。Kilosort4 默认仅在 ACG 零点附近出现重复峰且波形证据支持时调整；不得超过 0.5 ms。过大会破坏不应期和 ACG/CCG 估计。

05 Unit 质控与人工复核

参数含义默认值推荐设置改变后的影响
放电率（Firing rate）unit 在有效记录时间内每秒的 spike 数。仅报告，不默认剔除结合脑区、细胞类型、记录时长和稳定性判断。最低阈值升高会移除稀疏放电 unit，也可能丢失真实低频细胞。
ISI violation window用于统计不应期违例的时间窗口。2 ms常从 1–2 ms 开始，并报告具体定义。窗口越大违例越多；不同研究的数值不可脱离定义直接比较。
SNR波形信号幅度相对背景噪声的指标。仅报告使用项目内一致算法并结合波形图；不要把跨软件阈值直接照搬。阈值升高提高保守性，但会对小振幅真实 unit 不利。
Amplitude stability振幅随时间的变化程度。全记录时间线检查是否单调衰减、突变或只在短时段存在，并与漂移图对应。稳定性要求过严会排除真实状态变化；过松会保留漂移/丢失 unit。
Contamination threshold允许的候选污染比例。不自动设为真值以 10% 作为可见参考线时必须说明估计方法，并与 ACG/波形共同判断。降低阈值会减少 unit 数并提高保守性，但估计本身也有误差。

06 TTL、行为与统一时间轴

参数含义默认值推荐设置改变后的影响
Behavior time column行为设备时间戳所在列。time_seconds优先转换为秒并保留原始列；若为帧号需提供帧率或逐帧时间。单位错误会产生 1000 倍或采样率倍的偏移。
TTL pairing行为脉冲与电生理脉冲如何对应。按顺序一一配对先核对数量和间隔；有漏脉冲时用间隔序列定位后再配对。一个漏脉冲会让后续全部按序配对错位。
Clock model从行为时钟映射到电生理时钟的函数。offset + slope × time先用线性模型；残差呈弯曲或分段跳变时才考虑分段/非线性。模型过于复杂会拟合脉冲噪声；过于简单会留下系统漂移。
Residual tolerance匹配后允许的最大时间误差。报告实际值，不自动隐藏根据任务时间尺度和设备精度设定；毫秒级 spike 响应需更严格。容差放宽会保留错配；过严会剔除正常 TTL 抖动。
Shared-clock assumption无 TTL 时是否把行为秒时间直接当作电生理秒时间。仅在未提供 TTL 时启用并警告只有系统确实共享硬件时钟或已在外部完成同步时使用。无法检测起始偏移和漂移，结论风险必须写入报告。

07 行为质量先于神经解释

参数含义默认值推荐设置改变后的影响
Condition column用于分组比较的 trial 字段。condition使用实验程序原始标签并建立数据字典。重新编码会改变分组和样本量，必须保留映射。
Reaction-time start/end计算反应时所用的两个事件。stimulus_onset → response按科学问题明确；运动开始、按键和奖励不能混用。终点事件不同会改变数值和神经对齐解释。
Minimum trials一个条件进入统计或解码所需的最低有效 trial 数。仅警告，不自动剔除依据效应大小、变异和验证方案做功效评估；不要固定套用一个数。阈值越高条件越稳定但可用 session 越少。
Outlier rule反应时或连续行为变量的异常值定义。不默认删除优先使用任务定义边界或稳健规则，并报告剔除数量。事后调整边界可能改变条件效应并引入偏差。

08 神经活动分析工作台

参数含义默认值推荐设置改变后的影响
Alignment event所有 trial 的时间零点。stimulus_onset（取决于事件表）按假设选择；刺激、运动、选择和奖励回答不同问题。更换事件会改变响应时间解释，不能只挑最显著者。
Window事件前后截取的时间范围。-1 到 +2 s覆盖 baseline 和预期响应，同时避免相邻 trial/事件重叠。过短漏掉慢响应；过长增加重叠和多重比较。
Bin sizePSTH 或计数特征的时间分箱宽度。50 ms快速感觉响应可用 5–20 ms；行为/群体趋势常用 20–100 ms，并做敏感性比较。小 bin 提高时间分辨率但噪声大；大 bin 平滑响应并降低峰值。
Smoothing对分箱放电率施加的平滑核与宽度。默认最小或关闭图示可平滑，统计优先使用未平滑 trial 特征；报告核和宽度。平滑越强峰越低、响应越宽，可能制造相邻时间相关。
PSD method功率谱估计方法和分段设置。Welch平稳片段从 Welch 开始；报告窗长、重叠、频率分辨率和单位。长窗提高频率分辨率但降低时间局部性；短窗相反。
Surrogates通过时间移位或标签打乱建立机会分布的次数。200（演示）正式分析通常至少 1,000，尾部 p 值需要更多；固定随机种子。次数少运行快但 p 值分辨率低；次数多更稳定但耗时增加。

09 从图到统计证据

参数含义默认值推荐设置改变后的影响
Sampling unit进入推断统计的独立观察单位。必须由用户确认动物层结论通常以动物为独立单位；unit/session 可作为嵌套层。选得过细会虚增 n 和显著性；过粗会损失信息。
Paired两个条件是否来自同一对象或匹配单元。根据设计同一 unit/session/animal 的前后比较使用配对；不同对象使用非配对。配对指定错误会改变误差项和检验效能。
Alpha预先定义的 I 类错误阈值。0.05在分析前设定，并与多重比较方法一起报告。降低 alpha 更保守但增加漏检；不能为获得显著而事后调整。
Multiple comparison一组相关检验的错误率控制方法。FDR Benjamini–Hochberg探索性多单元/多时间窗可用 FDR；少量预设比较可用 Holm；报告 family 定义。更严格校正减少假阳性但降低功效；不定义检验族会使校正失去意义。
Resamples置换或 bootstrap 重复次数。1,000快速预览 200–1,000；最终估计常用 5,000–10,000 并固定种子。次数决定 p 值/区间的蒙特卡洛稳定性和运行时间。

10 机器学习、聚类与数据泄漏

参数含义默认值推荐设置改变后的影响
Feature window每个 trial 提取神经特征的时间范围。0–0.5 s（依任务而定）根据因果时间关系预先定义；预测行为时避免使用行为发生后的信息。更长窗口包含更多信息，也更容易混入后续事件和运动。
Cross-validation训练/验证数据划分与重复方式。5-fold stratified 或 grouped同一 session/动物不能跨折泄漏时使用 GroupKFold/LeaveOneGroupOut。随机 trial 划分通常分数更高，但可能只学到 session 身份。
Scaling特征标准化或归一化。线性/SVM 模型使用 StandardScaler必须在每个训练折拟合，再应用到验证折。全数据先标准化会泄漏验证集均值和方差。
Class weighting对不平衡类别的损失权重。balanced（不平衡时）先报告类别数；使用权重或重采样时只能在训练折内完成。会改变决策边界和概率校准，不能只报告普通准确率。
Permutation count打乱标签并重跑完整验证的次数。200（演示）正式结果至少 1,000，并保持分组结构不被破坏。只打乱一次不能形成稳定机会分布；错误打乱会破坏嵌套结构。

11 论文图与可复现导出

参数含义默认值推荐设置改变后的影响
Format图像文件类型。PNG + SVGPNG 用于快速预览；SVG/PDF 用于矢量编辑和出版。栅格格式受 DPI 限制；矢量格式保留线和文字对象。
Figure size输出宽度和高度。按当前图按期刊单栏/双栏毫米尺寸设置，再检查最长标签是否溢出。尺寸改变会影响文字相对大小和 panel 间距。
DPI栅格输出每英寸像素数。300线图 300–600 DPI；显微/热图按期刊要求和原始分辨率。DPI 越高文件越大，但不能增加原始数据分辨率。
Axis/grid/spine坐标轴线宽、长度、刻度、网格和边框显示。NeuroFlow 标准主题按图类型调整并保持同一 Figure 内一致；不要用装饰网格掩盖数据。粗线提高可见性但会压缩小 panel；网格过强会与数据竞争。
Project source mode项目使用外部只读索引还是内部原始副本。取决于导入选择长期归档前检查所有外部路径；需要独立移动时复制原始数据或使用可访问共享路径。清单始终可打开，但外部源丢失后依赖原始电压的步骤不能重跑。
