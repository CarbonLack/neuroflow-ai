01

从数据结构开始

这一页不是简单的“选文件”。NeuroFlow 必须先知道每个采样值怎样存储、多少个值组成一个时间点、探针通道怎样排列，以及行为事件使用哪一台设备的时钟。只有这些结构被确认，后面的滤波、sorting 和事件对齐才有正确的物理单位。导入过程保持原始数据只读，项目只保存索引、缓存和派生结果。

开始前准备

准备记录系统说明、采样率、总通道数、数据类型、增益或 μV/bit、探针几何，以及可选的事件 CSV。若是通用二进制，必须从采集软件配置中核对，而不是凭波形猜参数。

可执行操作与目的

操作怎么做目的结果
创建空项目先指定项目名称和保存目录，再从项目内导入数据。把原始数据与分析产物分开，并建立后续恢复入口。生成 neuroflow_project.json、derived、results 和 exports 目录。
导入通用二进制选择 .bin/.dat/.raw，填写采样率、通道数、dtype 和 μV/bit。读取没有自描述元数据的交错通道记录。验证文件大小能否被“通道数 × 每样本字节数”整除，并显示波形。
导入记录系统文件选择 Intan、Open Ephys、SpikeGLX、Blackrock、Plexon、TDT 或 NWB。利用 SpikeInterface extractor 读取设备元数据并建立统一缓存。项目中保存标准 int16 缓存，源文件保持不变。
从已有 sorting 继续选择 Kilosort/Phy、IBL ALF 或含 Units 的 NWB。跳过无法重复的原始处理阶段，直接进入 Unit 和下游分析。统一得到以秒表示的 spike times、unit ID 和来源记录。

参数说明

参数含义默认值推荐设置改变后的影响
采样率（Sampling rate）每秒采样点数，用于样本索引与秒之间的换算。模拟项目 30,000 Hz；设备文件读取元数据必须使用采集系统记录值；常见细胞外 spike 记录为 20–30 kHz。填小会把时间拉长、频率压低；填大会把时间压短、频率抬高。
总通道数（Channel count）二进制每个时间点包含的全部通道，包括文件中的辅助通道。模拟项目由电极模板决定按文件实际写入通道数填写，不等同于用于 sorting 的电生理通道数。错误值会重排整个文件，常出现重复、错位或斜纹波形。
数据类型（dtype）每个样本在磁盘上的存储类型。int16优先从设备元数据或导出设置读取；不要把 float32 文件当作 int16。错误 dtype 会改变帧长度和数值解释，可能仍能打开但波形完全错误。
µV / bit一个整数 ADC 步长对应的微伏数。通用导入 0.195；设备导入读取或标准化使用设备增益换算；若不确定，先保留原始计数并标记单位未知。只影响振幅单位和依赖振幅的阈值，不改变 spike 的样本位置。
复制源文件（Copy source）决定项目保存只读路径还是把原始二进制复制到项目。关闭：只读索引数据位置稳定时用索引；需要移动或长期归档项目时开启复制。复制提高可移植性但占用额外磁盘；索引节省空间但源路径失效后无法重读。

本页每个控件

数据来源 / Source
决定读取适配器；选择错误不会改变文件，但会导致校验失败。
项目名称 / Project name
用于项目文件夹和清单显示，不改变原始文件名。
采样率 / Sampling rate
把采样点转换成秒；错误值会使全部时间分析失真。
通道数 / Channel count
决定二进制重排；错误值常表现为重复或斜纹波形。
dtype 与 μV/bit
决定每个样本的字节解释和电压换算。

推荐顺序

  1. 先创建项目，再选择与你手中真实文件相符的入口。
  2. 导入后只查看 50–100 ms 波形，确认通道数量、振幅单位和时间长度。
  3. 保存项目；重新打开 neuroflow_project.json 应回到上次页面和工作流状态。

常见错误

  • 把 384 个电生理通道误当作文件总通道数，而文件实际还含同步通道。
  • 移动外部原始文件后仍期待只读索引自动找到新位置。
  • IBL ALF 或 Units-only NWB 不含原始电压，不能回到 sorting 之前。

输入、输出与验收检查

输入：记录系统原始文件、探针信息、事件日志

输出：只读数据源与 NeuroFlow 项目清单

检查：核对文件大小、采样率、通道数、数据类型，以及事件单位是秒、毫秒还是采样点。导入后先观察波形是否符合预期。

下一步： 确认结构后进入原始质控；如果只有处理后 spike，则直接进入 Unit 质控。

02

原始信号质控

质控的目标不是自动删除通道，而是建立证据：异常发生在哪些通道、哪些时间、哪些频率，以及是否可能影响重参考和 spike 检测。先在整段记录上定位问题，再放大到原始波形核实，最后才给出坏通道候选。

开始前准备

确保数据结构页的采样率、通道数、单位和记录时长已经核对。

可执行操作与目的

操作怎么做目的结果
多通道原始波形用时间窗、起点、通道范围和显示增益逐段浏览。识别饱和、跳变、运动伪迹、死通道和共同噪声。得到可缩放的真实电压片段和当前窗口 RMS。
质控指标总览运行该子分析，查看每通道 RMS、峰峰值、饱和比例和工频比值。用多个指标共同筛选，而不是依赖单一阈值。生成候选坏通道表；不会自动排除。
通道 × 频率功率查看所有通道的功率谱热图并缩放可疑频带。区分宽带噪声、50/60 Hz 工频和局部通道异常。得到各通道频谱证据和工频峰值。
质量时间线按时间块计算振幅、噪声和饱和指标。发现只在部分记录中出现的掉线、漂移或伪迹。得到异常时间段，供预处理中的排除或修复使用。

参数说明

参数含义默认值推荐设置改变后的影响
起始时间（Time start）当前预览窗口从记录的哪一秒开始。0 s先看开头，再抽查中段、结尾和任务关键事件附近。只改变显示和局部指标，不裁剪原始数据。
时间窗（Window）一次显示多少毫秒或秒。60 msspike 波形用 20–100 ms；慢伪迹和节律可用 1–10 s。短窗看波形细节，长窗看趋势，但过长会压缩尖峰。
通道范围（Channel range）同时绘制的起始通道与数量。Ch 0–11密集探针每次看 8–16 通道，并沿深度移动。通道过多会降低单通道可读性；过少可能看不到空间共同模式。
显示增益（Display gain）仅控制各通道在图中的垂直放大倍数。1.0×从 1.0× 开始，波形重叠时调低，振幅过小时调高。不改变数据和 QC 数值，只改变可视化。
工频（Line frequency）用于计算窄带工频功率的中心频率。50 Hz（中国与多数地区）按实验所在地选择 50 或 60 Hz，并同时查看谐波。选错频率会漏报工频，但不会改变原始信号。

本页每个控件

通道 RMS
单击柱子查看通道号和 RMS；异常通道以警示色显示。
50 Hz 比值
比较工频功率与邻近频率背景，不等同于绝对噪声振幅。
坏通道建议
只是候选列表；应回到原始波形核实后再排除。
时间/通道/增益控件
用于定位异常，不修改原始记录。

推荐顺序

  1. 先运行总览和时间线，再用原始波形、频谱对每个候选异常交叉验证。
  2. 坏通道标签必须记录证据和人工决定，不在质控页直接删除。
  3. 质控结论保存后再进入预处理，避免重参考被异常通道污染。

常见错误

  • 把高放电通道误判为高噪声通道。
  • 只看记录开头几十毫秒就宣布整段记录质量良好。
  • 看到 50 Hz 峰就直接 notch，而不检查接地、参考和谐波。

输入、输出与验收检查

输入：原始宽带电压

输出：通道 RMS、通道-频率功率图、质量时间线、工频/饱和指标和候选标签

检查：先看时间线定位异常发生时段，再用可缩放原始波形和功率谱核实。候选坏通道必须人工确认，不自动删除。

下一步： 把确认的坏通道和异常时间段带入预处理，分别建立 AP 与 LFP 分支。

03

预处理不是固定配方

预处理不是“越多越干净”。每个操作都改变信号，因此必须说明目标、顺序和是否会在 sorter 内再次执行。NeuroFlow 默认先做短片段预览，让用户比较处理前后波形和频谱；确认后才把参数写入工作流。

开始前准备

先完成坏通道确认；明确当前目标是 AP/spike sorting、LFP，还是两者。

可执行操作与目的

操作怎么做目的结果
AP / sorting 预览选择高通/带通、参考方式和预览片段。突出快速动作电位并评估 sorter 输入。显示处理前后波形、频谱和 RMS 变化。
LFP 分支预览选择低通、降采样率和工频处理。保留低频群体活动并降低后续计算量。生成独立 LFP 处理链，不覆盖 AP 分支。
重参考比较比较 none、common median 和 common average。减少通道间共同噪声，同时检查是否传播坏通道伪迹。显示参考前后共同成分和单通道波形。
写入处理链确认预览后保存操作顺序和参数。使 sorting、LFP 和复现导出使用同一可追溯配置。项目记录处理链；原始文件仍保持只读。

参数说明

参数含义默认值推荐设置改变后的影响
AP 频段（AP band）提供给 spike 检测或预览的通带。300–6000 Hz先使用 sorter 或领域常见默认；根据采样率和频谱证据调整。高通太高会削弱宽波形；太低会保留 LFP 漂移。低通不能超过 Nyquist。
LFP 低通（LFP low-pass）保留的最高 LFP 频率。300 Hz若只分析 <100 Hz，可设 150–250 Hz；研究高频振荡需提高并保留足够采样率。截止频率越低，尖锐瞬态越被平滑；过高会把 spike 泄漏带入 LFP。
降采样率（LFP sampling rate）滤波后 LFP 每秒保存的样本数。1,000 Hz至少为目标最高频率的 2 倍，实际通常保留 4–10 倍余量。过低会混叠或失去相位精度；过高增加内存和计算。
参考方式（Reference）从每个通道减去共同参考估计。Common median密集多通道记录可从 median 开始；稀疏 tetrode/微丝需结合分组和参考电极。average 更受极端通道影响；median 更稳健，但两者都可能移除真实共同活动。
陷波（Notch）压制 50/60 Hz 及可选谐波。默认关闭只有质控证据显示窄带污染且无法从硬件修复时开启。陷波会改变目标频率附近的振幅和相位，可能影响相位耦合分析。

本页每个控件

处理前/后波形
使用同一时间窗比较滤波和 common median reference 的影响。
预览节点
只计算短片段，不写回原始记录。
缩放工具
放大检查波形极性、边缘效应和伪迹残留。

推荐顺序

  1. AP 和 LFP 建立独立分支，不把同一处理链机械复用。
  2. 先预览再确认；图中同时保留原始、处理后和差值/频谱证据。
  3. 检查 sorter 是否内部执行滤波、whitening 和 drift correction，避免重复。

常见错误

  • 在外部和 Kilosort 内重复 whitening。
  • 坏通道未排除就做全局参考。
  • 先降采样再低通，造成混叠。

输入、输出与验收检查

输入：原始电压与坏通道列表

输出：AP/sorting 与 LFP 两条分支预览、处理链和运行前安全检查

检查：确认坏通道后再重参考；Neuropixels 先核对 inter-sample phase shift；避免在 sorter 内外重复 whitening；短片段预览不覆盖原始数据。

下一步： AP 分支进入 Spike sorting；LFP 分支保留到神经活动分析页。

04

Spike sorting 与工具选择

Spike sorting 把多通道电压中的候选事件分配给 unit。NeuroFlow 不把不同 sorter 的原生输出强行抹平：它保留原始文件、参数和日志，同时把共同结果转换为统一的 unit、spike 秒时间和通道/模板描述，供下游比较。

开始前准备

确认 AP 输入、探针几何、坏通道、可用硬件、输出目录和预计磁盘空间。

可执行操作与目的

操作怎么做目的结果
选择 sorter在表中选择 Kilosort4、MountainSort5 或其他已安装后端。按探针密度、硬件和研究需求选择算法，而不是只按“能运行”。参数区切换到该 sorter 的真实配置，未运行时显示输入预览。
运行所选 sorter确认弹窗中的数据、sorter、参数和运行位置。防止把耗时任务误运行在错误数据或错误配置上。保存原生输出、统一结果、版本、参数、日志和诊断图。
查看运行诊断切换 drift、spike 深度-时间、振幅、模板、相似度和运行日志。判断算法是否在整段记录和整个探针上稳定工作。得到进入 Unit QC 前的 sorting 证据。
比较 sorter激活不同结果并运行 unit 匹配与一致度比较。识别共识、拆分、合并和仅单一算法发现的 unit。真实数据报告 agreement；有 ground truth 的模拟数据才报告 accuracy。

参数说明

参数含义默认值推荐设置改变后的影响
Sorter实际执行的 spike sorting 后端。Kilosort4高密度 Neuropixels 优先评估 Kilosort4；稀疏/tetrode 可比较 CPU sorter。不同 sorter 的预处理、检测、聚类和资源需求不同，结果不可视为同一算法的参数变体。
n_chan_binKilosort 二进制文件中的总通道数，包括未用于 sorting 的通道。从项目结构读取必须与文件物理布局一致；Neuropixels 1.0 常见文件总数为 385。错误值会产生重复斜纹或错位热图，应在运行前立即停止。
batch_sizeKilosort 每个批次处理的样本数。60,000（30 kHz 时 2 s）先用默认；≤64 通道且漂移估计不稳时可增加批次包含的时间。更大批次需要更多显存/内存；过短批次用于漂移估计的 spike 更少。
nblocks漂移校正时沿探针深度分块的数量。1（刚性漂移）单 shank Neuropixels 可从 1 开始，非刚性漂移可试 5；≤64 通道或稀疏间距约 ≥50 µm 时考虑 0。0 跳过漂移校正；分块过多会在 spike 稀少时产生不稳定估计。
Th_universal / Th_learned通用模板和学习模板的 spike 检测阈值。Kilosort4 当前默认先用默认；漏检或 unit 时隐时现时每次只降低 1–2，并比较噪声和召回。阈值降低会检出更多事件，也会增加噪声和计算量。
tmin / tmax参与 sorting 的起止秒数。整段记录只有开头或结尾存在已确认伪迹时裁剪，并在审计记录写明。缩短可加快测试，但短片段结果不能代替整段稳定性评估。
duplicate_spike_ms同一 unit 中过近 spike 被判为重复并移除的窗口。Kilosort4 默认仅在 ACG 零点附近出现重复峰且波形证据支持时调整；不得超过 0.5 ms。过大会破坏不应期和 ACG/CCG 估计。

本页每个控件

Sorter 表
显示全部候选工具、安装状态、硬件和适用记录；单击选择。
参数预设
把电极类型映射到一组可审计参数，仍允许逐项修改。
运行当前节点
使用当前选择真实执行 sorter，并保存完整日志和输出目录。
诊断视图
检查 drift、振幅、模板、相似度、污染率和导出文件。

推荐顺序

  1. 先用默认参数跑一段代表性数据检查输入和资源，再运行整段记录。
  2. Kilosort 的 drift、depth-time、amplitude、template 和 similarity 图都应查看。
  3. 保留 sorter 原生目录；统一格式只服务跨工具衔接，不替代原生证据。

常见错误

  • 未实际运行所选 sorter，却显示另一个 sorter 的旧结果。
  • 把真实数据上两个 sorter 的一致度写成准确率。
  • 只看 unit 数量，忽略漂移、重复、振幅和日志。

输入、输出与验收检查

输入：高采样率多通道记录、探针几何与 sorter 参数

输出：各 sorter 原生文件、统一秒级 Unit/spike 结果、参数、日志与比较证据

检查：先确认环境状态与探针适用性。Kilosort4 适合高密度探针；MountainSort5 更偏 CPU/tetrode，可选择 Scheme 1/2/3。运行多个 sorter 后检查 Hungarian 匹配、一致度、独有 Unit 和共识 Unit；真实数据的一致度不能称为准确率。

下一步： 选择一个 active sorting 结果，进入 Unit 质控；必要时再回到本页比较 sorter。

05

Unit 质控与人工复核

Sorter 输出的是候选 cluster。Unit 质控把放电率、不应期、信噪比、波形、振幅随时间和自相关图放在一起，让研究者给出可追溯的保留、MUA、噪声或待定判断。任何单一阈值都不能替代人工复核。

开始前准备

先在 sorting 页确认 active 结果、运行日志和漂移诊断。

可执行操作与目的

操作怎么做目的结果
指标散点与筛选选择 x/y 指标、阈值和标签，点击点查看 unit。发现指标之间的权衡并快速定位异常 unit。得到候选筛选集合，不自动改变最终标签。
波形与模板查看主通道及相邻通道平均波形和变异。判断波形是否稳定、空间上是否合理、是否可能为噪声。生成 unit 级波形证据。

参数说明

参数含义默认值推荐设置改变后的影响
放电率（Firing rate）unit 在有效记录时间内每秒的 spike 数。仅报告，不默认剔除结合脑区、细胞类型、记录时长和稳定性判断。最低阈值升高会移除稀疏放电 unit，也可能丢失真实低频细胞。
ISI violation window用于统计不应期违例的时间窗口。2 ms常从 1–2 ms 开始，并报告具体定义。窗口越大违例越多；不同研究的数值不可脱离定义直接比较。
SNR波形信号幅度相对背景噪声的指标。仅报告使用项目内一致算法并结合波形图；不要把跨软件阈值直接照搬。阈值升高提高保守性，但会对小振幅真实 unit 不利。
Amplitude stability振幅随时间的变化程度。全记录时间线检查是否单调衰减、突变或只在短时段存在，并与漂移图对应。稳定性要求过严会排除真实状态变化；过松会保留漂移/丢失 unit。
Contamination threshold允许的候选污染比例。不自动设为真值以 10% 作为可见参考线时必须说明估计方法，并与 ACG/波形共同判断。降低阈值会减少 unit 数并提高保守性，但估计本身也有误差。

本页每个控件

Unit 表
每行是一个候选 unit；单击图中点或表格查看指标。
ISI violation

推荐顺序

  1. 先看总体分布，再逐个复核临界和高影响 unit。
  2. 阈值只生成候选标签；最终决定必须记录 reviewer、时间和备注。
  3. 更换 active sorter 后重新计算 QC，不能沿用旧结果。

常见错误

  • 用单一 SNR 或 ISI 阈值宣布“好神经元”。
  • 把 unit 数量当作 recording yield 而不报告筛选过程。
  • 人工修改标签却不保存审计记录。

输入、输出与验收检查

输入：Spike times、波形、模板和记录时长

输出：放电率、ISI 违例、SNR、标签与复核表

检查：点击散点查看 unit 指标；阈值是筛选规则，不是生物学真值；保留人工修改记录。

06

TTL、行为与统一时间轴

行为电脑、视频和电生理设备通常各有自己的时钟。同步页把成对 TTL 脉冲用于估计 offset + slope × behavior_time，并用残差判断是否存在漏脉冲、错配或非线性漂移。没有对应 TTL 时只能假设共用时钟，界面会明确标注。

开始前准备

准备行为事件 CSV 和可选 TTL CSV；明确每一列的时钟、单位和事件含义。

可执行操作与目的

操作怎么做目的结果
导入行为事件选择包含 time_seconds、trial、condition 和 event_type 的 CSV。建立 trial 语义和行为时钟中的事件序列。项目保存事件表和源文件路径。
导入 TTL选择包含与行为同步脉冲一一对应的电生理时间 CSV。建立两个设备时钟之间的可估计映射。显示可匹配数量、缺失和重复脉冲。
拟合统一时间轴按事件顺序匹配并拟合截距与斜率。校正起始偏移和线性时钟漂移。生成 ephys 秒时间、残差、drift ppm 和 trial 表。
检查同步证据查看残差随时间、事件计数和异常配对。判断线性映射是否足够，是否需要重新配对或分段。保留同步质量报告供所有事件对齐分析引用。

参数说明

参数含义默认值推荐设置改变后的影响
Behavior time column行为设备时间戳所在列。time_seconds优先转换为秒并保留原始列；若为帧号需提供帧率或逐帧时间。单位错误会产生 1000 倍或采样率倍的偏移。
TTL pairing行为脉冲与电生理脉冲如何对应。按顺序一一配对先核对数量和间隔；有漏脉冲时用间隔序列定位后再配对。一个漏脉冲会让后续全部按序配对错位。
Clock model从行为时钟映射到电生理时钟的函数。offset + slope × time先用线性模型；残差呈弯曲或分段跳变时才考虑分段/非线性。模型过于复杂会拟合脉冲噪声；过于简单会留下系统漂移。
Residual tolerance匹配后允许的最大时间误差。报告实际值，不自动隐藏根据任务时间尺度和设备精度设定；毫秒级 spike 响应需更严格。容差放宽会保留错配；过严会剔除正常 TTL 抖动。
Shared-clock assumption无 TTL 时是否把行为秒时间直接当作电生理秒时间。仅在未提供 TTL 时启用并警告只有系统确实共享硬件时钟或已在外部完成同步时使用。无法检测起始偏移和漂移，结论风险必须写入报告。

本页每个控件

事件数量
确认行为、TTL 和神经数据中的事件能一一对应。
时间残差
显示配对事件的偏差；随时间变化提示时钟漂移。
trial 表
保存条件、事件时间和排除标记，供后续分析使用。

推荐顺序

  1. 导入后先看事件和 TTL 数量、间隔，再拟合。
  2. 残差图必须覆盖整段记录，不能只报告平均误差。
  3. 同步映射、源列、单位和排除配对全部保存到项目。

常见错误

  • 把行为毫秒当成秒。
  • 有漏脉冲仍按行号强制一一对应。
  • 没有 TTL 却报告精确同步误差。

输入、输出与验收检查

输入：Spike 秒时间、TTL、行为事件和视频帧

输出：统一秒时间轴、匹配残差与 trial 表

检查：核对事件数量、顺序、匹配残差、漂移趋势、丢帧和重复脉冲。

下一步： 用同步后的 trial 表先检查行为质量，再进行事件对齐神经分析。

07

行为质量先于神经解释

行为分析先回答实验是否按设计执行：各条件有多少 trial、选择是否平衡、反应时是否合理、缺失和排除发生在哪里。只有行为结构可靠，神经响应和机器学习标签才有可解释含义。

开始前准备

同步页已生成统一秒时间和 trial 表，并明确 trial 开始、事件和结束。

可执行操作与目的

操作怎么做目的结果
条件计数查看每个刺激、选择、结果或组别的 trial 数。发现类别不平衡和设计遗漏。输出可用于统计和解码的有效样本数。
反应时绘制分布、条件比较和异常 trial。识别过快猜测、超时和记录错误。生成反应时变量和排除候选。
心理测量曲线按刺激强度计算选择比例和样本量。检查行为是否随任务变量系统变化。输出曲线、每点 trial 数和拟合参数。
trial 排除依据预先定义规则标记缺失、超时、伪迹或异常值。让排除发生在看神经结果之前，减少结果导向筛选。保留原 trial 和 exclusion_reason，不物理删除。

参数说明

参数含义默认值推荐设置改变后的影响
Condition column用于分组比较的 trial 字段。condition使用实验程序原始标签并建立数据字典。重新编码会改变分组和样本量，必须保留映射。
Reaction-time start/end计算反应时所用的两个事件。stimulus_onset → response按科学问题明确；运动开始、按键和奖励不能混用。终点事件不同会改变数值和神经对齐解释。

条件计数

推荐顺序

  1. 行为图先于神经图生成并保存。
  2. 每个图点都可点击查看刺激水平、样本量和原始 trial。
  3. 排除规则保存为字段和日志，不覆盖原始 trial 表。

常见错误

  • 类别严重不平衡仍只报告普通准确率。
  • 看完神经差异后再调整行为排除规则。
  • 把 trial、session 和动物混为一个样本层级。

检查：点击曲线点查看刺激水平与样本量；检查缺失值、极端反应时和类别不平衡。

08

神经活动分析工作台

神经活动页不是一张固定 PSTH，而是四类可独立运行的分析入口：事件对齐响应、spike train 统计、LFP 频谱/时频，以及 spike-field 耦合。每个子分析都有自己的输入、参数、图和表；未运行时显示输入预览和运行目的，不伪造结果。

开始前准备

确认 active units、同步事件、有效 trial；LFP 或耦合分析还需要原始/LFP 电压。

可执行操作与目的

操作怎么做目的结果
事件对齐 Raster/PSTH选择事件、窗口、bin、平滑、baseline 和条件。描述 unit 或群体在事件前后的时间响应。输出 raster、PSTH、热图、响应窗口和 trial 级特征。
Spike train 统计选择 CV2、Lv、Fano、ACG/CCH、STTC 或距离。量化放电规律性、变异和神经元间时间关系。生成单位明确的指标表和 correlogram。
LFP 分析运行 PSD、频带功率、coherence 或时频图。描述振荡功率、跨通道关系和事件相关频谱变化。输出频谱、时频矩阵、频带汇总和方法参数。
Spike-field 耦合选择相位频带、参考通道、spike 集合和 surrogate。检验 spike 是否偏好某一 LFP 相位，并评估机会水平。输出相位分布、向量强度、Rayleigh/置换证据和 PAC/STA。

参数说明

参数含义默认值推荐设置改变后的影响
Alignment event所有 trial 的时间零点。stimulus_onset（取决于事件表）按假设选择；刺激、运动、选择和奖励回答不同问题。更换事件会改变响应时间解释，不能只挑最显著者。
Window事件前后截取的时间范围。-1 到 +2 s覆盖 baseline 和预期响应，同时避免相邻 trial/事件重叠。过短漏掉慢响应；过长增加重叠和多重比较。
Bin sizePSTH 或计数特征的时间分箱宽度。50 ms快速感觉响应可用 5–20 ms；行为/群体趋势常用 20–100 ms，并做敏感性比较。小 bin 提高时间分辨率但噪声大；大 bin 平滑响应并降低峰值。
Smoothing对分箱放电率施加的平滑核与宽度。默认最小或关闭图示可平滑，统计优先使用未平滑 trial 特征；报告核和宽度。平滑越强峰越低、响应越宽，可能制造相邻时间相关。
PSD method功率谱估计方法和分段设置。Welch平稳片段从 Welch 开始；报告窗长、重叠、频率分辨率和单位。长窗提高频率分辨率但降低时间局部性；短窗相反。
Surrogates通过时间移位或标签打乱建立机会分布的次数。200（演示）正式分析通常至少 1,000，尾部 p 值需要更多；固定随机种子。次数少运行快但 p 值分辨率低；次数多更稳定但耗时增加。

本页每个控件

Unit 选择
选择一个 unit 后，Raster、PSTH 和摘要同步更新。
Raster
每行一个 trial，每个短线一个 spike，保留试次差异。
PSTH
对 spike 分箱并跨 trial 平均；分箱宽度影响平滑程度。
Spike train 统计
CV2、Lv、Fano、CCH、STTC 和距离回答不同的变异性、相关性或相似性问题。
LFP
PSD、coherence、相位延迟和时频图使用带单位的 Neo 信号与 Elephant/SciPy 计算。
Spike-field
相位锁定必须说明参考频段、相位定义、spike 数和 surrogate 方法。
呼吸案例
只在 NeuroFlow 模拟数据上验证论文方法结构，不复制原图或数值结论。

推荐顺序

  1. 每次只运行一个明确子分析，并在运行前阅读输入和参数摘要。
  2. 图和统计共享同一 trial、窗口和条件定义，但统计不依赖图形平滑。
  3. 保留每个子图对应的数据表，允许单独编辑和导出。

常见错误

  • 未运行新选项时仍显示其他分析的旧图。
  • 用平滑后的 PSTH 每个时间点直接做大量 t 检验。
  • LFP 未抗混叠降采样或 spike-field 使用同一电极造成 spike 泄漏。

输入、输出与验收检查

输入：Unit spike times、对齐事件、原始/LFP 电压、分析窗口与条件

输出：Raster/PSTH、CV2/Lv/Fano、CCH/STTC/距离、PSD/coherence/时频图、相位锁定和 PAC

检查：先确认当前选项属于 spike、LFP 还是联合分析；检查分箱、频段、窗口、相位参考和 surrogate 次数；案例结果只验证方法结构。

09

从图到统计证据

统计页从“样本是什么”开始，而不是从检验名称开始。trial 嵌套于 session，unit 嵌套于动物；配对、重复测量和层级结构决定了哪些比较合法。页面同时报告效应量、置信区间和多重比较处理，不把 p 值作为唯一结论。

开始前准备

准备未平滑的 trial 级指标、条件、unit/session/animal 标识和排除规则。

可执行操作与目的

操作怎么做目的结果
设计检查指定样本单位、配对关系、层级和主要比较。防止伪重复和把嵌套样本当独立样本。生成可审计的统计设计摘要。
参数/非参数比较根据设计选择 t/Welch/ANOVA 或 Wilcoxon/Mann–Whitney/Kruskal。在假设和数据结构匹配的前提下比较条件。输出统计量、p 值、效应量、置信区间和样本数。
置换/Bootstrap按合法交换单位打乱标签或重采样。在分布假设较弱时建立零分布或置信区间。保存随机种子、次数和完整机会分布。
混合效应模型设置固定效应和 animal/session/unit 随机效应。处理分层、缺失和不平衡重复测量。输出模型式、系数、区间、收敛和诊断。

参数说明

参数含义默认值推荐设置改变后的影响
Sampling unit进入推断统计的独立观察单位。必须由用户确认动物层结论通常以动物为独立单位；unit/session 可作为嵌套层。选得过细会虚增 n 和显著性；过粗会损失信息。
Paired两个条件是否来自同一对象或匹配单元。根据设计同一 unit/session/animal 的前后比较使用配对；不同对象使用非配对。配对指定错误会改变误差项和检验效能。
Alpha预先定义的 I 类错误阈值。0.05在分析前设定，并与多重比较方法一起报告。降低 alpha 更保守但增加漏检；不能为获得显著而事后调整。
Multiple comparison一组相关检验的错误率控制方法。FDR Benjamini–Hochberg探索性多单元/多时间窗可用 FDR；少量预设比较可用 Holm；报告 family 定义。更严格校正减少假阳性但降低功效；不定义检验族会使校正失去意义。
Resamples置换或 bootstrap 重复次数。1,000快速预览 200–1,000；最终估计常用 5,000–10,000 并固定种子。次数决定 p 值/区间的蒙特卡洛稳定性和运行时间。

本页每个控件

视图选择
在效应、多重比较、分布假设和混合模型诊断间切换。
表格
提供统计量、p 值、校正值、效应量和置信区间。
样本单位
必须区分 trial、unit、session 和动物，避免伪重复。

推荐顺序

  1. 先生成统计设计卡，再允许选择检验。
  2. 同时报告原始数据点、效应量、置信区间、p 值和校正方法。
  3. 将完整统计表与生成图所用汇总分开保存。

常见错误

  • 3 只动物的 300 个 unit 被当作 n=300 独立样本。
  • 对每个 PSTH 时间 bin 做检验却不校正。
  • 只报告 p 值，不报告方向、大小和不确定性。

输入、输出与验收检查

输入：Trial 级指标、条件标签和层级信息

输出：样本层级、参数/非参数检验、圆周/置换检验、效应量、置信区间、混合模型和校正值

检查：查看正态性、配对关系、方差、伪重复和多重比较；相位数据使用圆周统计并与 circular-shift surrogate 对照；同时报告效应量与置信区间。

10

机器学习、聚类与数据泄漏

机器学习页把神经活动转换为 trial × feature 矩阵，并把预处理、特征选择和模型全部放入交叉验证内部。核心不是寻找最高分，而是建立没有数据泄漏、与 shuffle 基线比较、能跨 session/动物泛化的评估。

开始前准备

确定预测目标、特征时间窗、分组变量、类别平衡和最小样本量。

可执行操作与目的

操作怎么做目的结果
分类选择 Logistic regression、SVM、Random forest、XGBoost 等模型。预测离散刺激、选择或结果标签。输出 balanced accuracy、F1、AUC、混淆矩阵和每折分数。
回归选择线性、Ridge、随机森林等回归模型。预测位置、速度、反应时或连续刺激变量。输出 R²、MAE、预测-真实图和残差。
时间分辨解码在滑动时间 bin 内重复完整交叉验证。估计可预测信息随事件时间的变化。输出时间曲线、机会分布和多重比较结果。
PCA 与聚类对神经群体特征降维或无监督分组。探索群体结构，不把可视化分离自动当作统计证据。输出解释方差、载荷、投影和聚类稳定性。

参数说明

参数含义默认值推荐设置改变后的影响
Feature window每个 trial 提取神经特征的时间范围。0–0.5 s（依任务而定）根据因果时间关系预先定义；预测行为时避免使用行为发生后的信息。更长窗口包含更多信息，也更容易混入后续事件和运动。
Cross-validation训练/验证数据划分与重复方式。5-fold stratified 或 grouped同一 session/动物不能跨折泄漏时使用 GroupKFold/LeaveOneGroupOut。随机 trial 划分通常分数更高，但可能只学到 session 身份。
Scaling特征标准化或归一化。线性/SVM 模型使用 StandardScaler必须在每个训练折拟合，再应用到验证折。全数据先标准化会泄漏验证集均值和方差。
Class weighting对不平衡类别的损失权重。balanced（不平衡时）先报告类别数；使用权重或重采样时只能在训练折内完成。会改变决策边界和概率校准，不能只报告普通准确率。
Permutation count打乱标签并重跑完整验证的次数。200（演示）正式结果至少 1,000，并保持分组结构不被破坏。只打乱一次不能形成稳定机会分布；错误打乱会破坏嵌套结构。

本页每个控件

任务与模型
选择分类或回归算法；选择后只有点击运行才会训练。
交叉验证
每折只用训练数据拟合预处理，测试折用于独立评价。
置换基线
打乱标签形成零假设分布，用于判断模型是否超过偶然水平。
PCA/聚类
用于探索群体结构，不自动提供科学因果解释。

推荐顺序

  1. 先建立线性基线，再比较复杂模型。
  2. 模型、特征选择、缩放和超参数搜索全部封装在验证循环内。
  3. 报告每折分数、shuffle 分布和跨组泛化，而不是一个最高分。

常见错误

  • 同一 session 的相邻 trial 同时进入训练和测试。
  • 用全数据选择神经元后再交叉验证。
  • 比较多个模型后只展示最高结果，不披露选择过程。

输入、输出与验收检查

输入：Trial × feature 矩阵、标签和分组变量

输出：多模型交叉验证、AUC/F1、混淆矩阵、置换、PCA 与聚类

检查：预处理只在训练折拟合；同一动物/session 用分组拆分；与 shuffle 基线比较；不要挑选最好模型后隐瞒比较过程。

论文图与可复现导出

导出页把图、绘图数据、统计表、Methods、软件环境和工作流绑定在一起。图形编辑不会改写分析数据；重新计算和视觉调整是两条独立审计记录。项目保存后，可通过 neuroflow_project.json 恢复已完成步骤和 active 结果。

开始前准备

确认图中的坐标、单位、样本量、误差定义和统计标注均来自已保存结果。

可执行操作与目的

操作怎么做目的结果
编辑当前图双击坐标轴或打开 Figure Studio，修改对象级样式。在不重算数据的前提下完成论文版式。修改线、点、柱、热图、文字、坐标、刻度、网格和图例。
单独保存子图从图表面板选择子图，设置精确尺寸并导出。避免整页截图造成分辨率和排版问题。输出 PNG、SVG 或 PDF，并保留背景和字体设置。
导出数据与统计表保存当前图背后的 x/y/分组数据和完整统计结果。让读者能从图回到数值，并允许在外部软件复核。输出 CSV/JSON 表和来源索引。
保存/恢复项目点击保存项目，之后从首页打开 neuroflow_project.json。恢复数据来源、工作流状态、sorter 结果、分析表和审计日志。重新打开后定位到上次保存页面，已完成节点可直接查看。

参数说明

参数含义默认值推荐设置改变后的影响
Format图像文件类型。PNG + SVGPNG 用于快速预览；SVG/PDF 用于矢量编辑和出版。栅格格式受 DPI 限制；矢量格式保留线和文字对象。
Figure size输出宽度和高度。按当前图按期刊单栏/双栏毫米尺寸设置，再检查最长标签是否溢出。尺寸改变会影响文字相对大小和 panel 间距。
DPI栅格输出每英寸像素数。300线图 300–600 DPI；显微/热图按期刊要求和原始分辨率。DPI 越高文件越大，但不能增加原始数据分辨率。
Axis/grid/spine坐标轴线宽、长度、刻度、网格和边框显示。NeuroFlow 标准主题按图类型调整并保持同一 Figure 内一致；不要用装饰网格掩盖数据。粗线提高可见性但会压缩小 panel；网格过强会与数据竞争。
Project source mode项目使用外部只读索引还是内部原始副本。取决于导入选择长期归档前检查所有外部路径；需要独立移动时复制原始数据或使用可访问共享路径。清单始终可打开，但外部源丢失后依赖原始电压的步骤不能重跑。

本页每个控件

图形设置
修改当前图的标题、坐标、范围和网格。
SVG/PDF/PNG
SVG/PDF 保留矢量元素；PNG 用于快速预览。
CSV 与 Methods
同时导出绘图数据、统计表、参数、版本和方法草稿。
项目清单
记录来源和执行状态，使结果能回到对应输入与参数。

推荐顺序

  1. 每张论文图同时保存矢量图、绘图数据、统计表和生成参数。
  2. 保存项目后关闭并重新打开一次，验证恢复位置和关键结果。
  3. 对外分享前检查源路径、许可证、匿名化和未发表数据权限。

常见错误

  • 只保存截图，没有绘图数据和统计来源。
  • 编辑图中文字后与实际单位或样本量不一致。
  • 只读索引指向个人临时目录，却把项目当作可独立归档。

输入、输出与验收检查

输入：分析对象、统计结果和绘图设置

输出：PNG/SVG、绘图数据、Methods、workflow 与 provenance

检查：检查坐标和单位、误差定义、颜色可辨识性、统计标注来源，并保留 SVG 和 CSV。
