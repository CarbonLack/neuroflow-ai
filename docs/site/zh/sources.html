方法与来源

NeuroFlow 复用成熟开源计算能力，自主编写界面、兼容、教程和审计层。以下内容为原创概括，不复制原文。

来源与借鉴范围

来源NeuroFlow 借鉴或调用的范围
Kilosort4 documentation文档层级、GUI 操作顺序、参数、导出文件、漂移检查和示例教程结构。
Kilosort4 GUI guide数据/探针选择、输入预览、通道数检查和运行顺序。
Kilosort4 parameter guiden_chan_bin、batch_size、nblocks、阈值、时间范围、几何和重复 spike 注意事项。
SpikeInterface数据读取、预处理、sorter 适配、后处理、质量指标和比较接口。
SpikeInterface sorters统一 sorter wrapper、原生依赖和容器执行机制。
Elephant基于 Neo 对象的 spike train 统计、频谱、相关、相位和信号分析 API。
Neo带单位的 SpikeTrain、AnalogSignal、Event、Epoch、Segment 和 Block 对象。
Physpike sorting 输出的人工复核工作流。
MountainSort5面向 CPU 的 sorting scheme 和包接口。
Respiration/PFC study行为状态、呼吸、spike、LFP、相位和 surrogate 分析的方法结构。
GraphPad Prism graph controls图元、坐标轴、网格、刻度和精确尺寸的可编辑交互预期。
IBL Brain-Wide Map公开神经与行为数据的验证背景。
DANDI Archive版本化 NWB 公开数据访问与来源记录。

不直接抄袭原则

NeuroFlow 不复制其他产品的原文、截图、论文图、数值结论或视觉识别；只把官方方法定义和文档组织方式作为参考，再自主编写产品文字、工作流、适配器和界面行为。
