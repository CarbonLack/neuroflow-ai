如何重新运行这项验证

How to rerun this validation

  1. 通过官方 ONE API 下载指定 IBL eID/PID 的 ALF trials 与 probe spike-sorting datasets。
  2. 从 DANDI 000552 的固定版本下载指定 asset；不要用 draft 或未记录版本替换。
  3. 在首页双击“公开数据验证”，选择 IBL ALF 或 DANDI/Buzsáki NWB 结构。
  4. 导入后核对 Unit、spike、trial、event、state 和 ripple 数量。
  5. 运行行为、事件分析、统计和机器学习；正式复现时增加置换次数并按论文筛选。
  6. 导出项目、统计表、图、版本和引用；将结果与本页数量及原论文代码逐项对照。
