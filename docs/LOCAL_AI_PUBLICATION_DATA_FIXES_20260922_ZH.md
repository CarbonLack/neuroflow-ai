# 2026-09-22 本地修正记录（未上传 GitHub）

本记录区分已验证功能与仍受外部环境限制的功能。当前正式发布版仍为 v1.3.5；本轮更改先放在本地测试版，不宣称已在线发布。

## AI 超时与错误

- 发现：Harness SDK 原先用同一个 180 秒硬截止覆盖启动、工具调用和模型生成，故同一模型会随响应耗时出现“有时成功、有时超时”。失败对话也缺少持久记录。
- 修正：超时改为按最后一条协议活动计算；Harness 旧设置低于 300 秒时升级为 300 秒默认无活动等待，同时保留整轮安全上限。AI 设置现可调整超时。错误包含初始化/生成阶段、已耗时和无活动时长，并保存在所属项目对话中。
- 限制：本机 `dsh --version` 当前报告 NVM4306（委托脚本身份无法读取）。这属于本机 Harness 启动器故障，模型请求甚至尚未发出；不能把应用的离线自检等同于在线模型通过。此前修复启动器曾遭权限拒绝，需管理员检查 NVM 信任链。不要将机构凭据复制进应用。

## 论文图与作图数据

- 第 11 步现为应用内主图/附图浏览器；左侧按论文顺序选图，右侧展示图、草拟英文图注和数据位置。原 HTML 仍作为可移植导出文件存在，但不再作为应用内看图的必经网站。
- 每次论文导出新增 `exports/data_catalog.json`：标出原始记录位置、是否在项目内部、是否仍存在、处理表和逐图数据对应关系。
- 每张图新增 `exports/figure_data/<图名>.json`（坐标轴、artist 类型、数组名称、来源区段、限制）和 `.npz`（绘图时实际使用的数值）。原始文件不在导出时复制；若原始记录位于项目之外，单独复制导出文件夹并不能替代原始文件。
- 应用中给 AI 附加当前图时，当前图及其绘图数组也保存到本项目的 `exports/figures/interactive_*.png` 和 `exports/figure_data/interactive_*.json/.npz`。发送前仍显示预览与数据传输提示。Harness 接收图与作图清单，并能通过受限工具按页读取数值；不会把整份原始电压文件发送出去。
- 数值文件保存 Matplotlib 中可访问的曲线、散点、图像、色块、线段与区域等绘制对象。文字与某些自定义 artist 未必能完整数值化；必须结合项目状态、原始文件、处理参数和 Methods 审核。不能只凭图像像素作定量结论。
