# 1.2.0 交付与使用记录

日期：2026-09-08。本轮是操作体验、教程和交付优化，不是重新分析真实实验数据。

## 现在怎么用

桌面原有的 **NeuroEphys AI** 快捷方式已更新，双击即可启动 v1.2.0。无需另外启动 Python。

- 第一次使用：打开“教程中心”，从“先用示例熟悉操作”开始。教程可搜索，操作步骤、参数说明和问题排查分别查看。
- 已有项目：使用“打开／导入项目”，选择已有项目；不要为了继续分析而重新新建。
- 想找功能：按 Ctrl+K。打开教程中心：Ctrl+Shift+H。
- 想调整空间：Ctrl+B 收放左侧导航，Ctrl+J 收放右侧 AI 助手；拖动分隔线调整三栏宽度。三栏可以同时显示。
- 图形相关设置：展开“图表工具”。窄窗口下控件换行，正文可以滚动。

## 主要修改

1. 保留紫黑配色和原 Logo 边框，首页集中呈现项目入口，减少重复说明和装饰。
2. 教程重做为 18 个具体任务，支持搜索、分类、字号调整和已读记录；取消难读的横向长表，补充结果检查与保存位置。
3. App 与中英文网页手册共用任务说明；更新真实界面截图、第一次练习和工作区说明。
4. 左侧导航更紧凑，图表工具可折叠，窄栏控件自动换行；保留右侧 AI 和三栏调整能力。
5. 增加功能查找、最近项目入口；切换项目前检查未保存内容及运行任务，修正单步任务的进度显示。
6. 测试及截图使用独立偏好文件，避免把测试项目写进用户的最近项目列表。
