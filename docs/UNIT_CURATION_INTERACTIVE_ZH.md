# 交互式 Unit 复核：图像含义与下游更新边界

## 当前实现

在「Unit 质控 → 人工 Unit 复核」中，默认显示当前 Unit 在峰值接点上的逐次原始 spike 波形、均值/中位数与第 10–90 百分位、同接点候选 cluster 的波形 PCA、振幅随记录时间的变化。接点选择器列出各接点的候选 cluster 数；PC 横轴和纵轴可在 PC1–PC3 间切换。点击 PCA 散点可切换左侧当前 Unit。

PCA 点的颜色是**已有 sorter 分配的候选 Unit**，不是 PCA 重新得到的聚类。PCA 特征由原始电压在 sorter spike 时间戳周围截取的同一接点片段重新计算，因此也不应误称为 Kilosort/其他 sorter 的原生 PC 特征。接点相同依据 Unit QC 的 `peak_channel`；没有接点几何时，不把数字相邻通道推断为空间相邻。

所有同接点候选 cluster 都列入比较，当前版本把可从原始记录安全读取的**全部有效 spike**画入 PCA 散点和逐次波形层，不再只显示几百个抽样点。PCA 点携带来源 Unit 与来源 spike 索引；切换 PC1–PC3 只改变观察投影，不改变选中集合。超大记录的绘制由 Matplotlib 集合对象批量提交，避免逐点创建控件造成的界面阻塞。

在 PCA 视图中启用套索后，可以圈出人眼判断为离群的一组 spike，并选择“排除选中 spike”或“拆分为新 Unit”。拆分只允许一次选中一个当前 cluster 的 spike，避免把不同来源 Unit 悄悄混成新细胞。每次编辑都写入 revision 和审计历史，支持逐步撤销；sorter 原始输出始终只读。这个设计借鉴 Offline Sorter/Phy 的核心人工复核意图——在多特征投影、波形和时间稳定性证据之间来回核对——但使用本项目自己的界面、数据结构和非破坏性来源记录。

## 人工结论和后续图

「保存本 Unit 结论」保存复核人、标签、置信度、检查项和审计记录。完成复核后，点击「应用已复核单神经元到下游分析」，App 会建立带 revision 的 Unit ID 清单：只纳入 `candidate_single_unit`，明确排除 MUA、噪声、伪迹、待定和未复核候选。该操作**不改写 sorter 原始 spike 归属**，并会清空内存中的旧事件、spike train、spike-field、统计和解码结果，将论文导出标记为过期。原项目 manifest 会先存入 `derived/curation_history`，用于回退和审计。

应用筛选集后，事件响应、spike train、连接性、群体动态和 spike-field 分析都从该清单读取 spike；统计和解码读取筛选后生成的事件结果。事件图标题与结果数据记录筛选 revision 和 Unit 清单。如果应用后又修改任何人工标签，筛选集会进入 `needs_reapply` 状态，下游运行会被阻止，直到研究者重新应用。纯 LFP、原始电压质控和行为图不依赖 Unit 清单，不会被无故改变。

## 行为事件 tuning

在「神经活动」页点击「选择行为事件 / Tuning」，可从项目内所有可用的非同步行为中选择 1 或 2 个条件。选择 1 个条件用于查看该行为相对事件前基线的 tuning；选择 2 个条件同时绘制两条 PSTH 并保留条件统计/解码入口。该选择会重新执行事件对齐，而不是只改图例。输出记录 `requested_conditions`、实际保留的事件数、排除原因、Unit 筛选 revision，并在组合图顶部显示所选行为和 Unit 范围。当前条件统计和分类解码按两条件设计，因此界面不允许一次把三个以上行为混成同一个比较；其他行为可换选后作为另一项有明确 provenance 的分析运行。

复核结论不等于真实单神经元身份。波形/PCA 形态需结合 ACG、不应期、漂移、跨 Unit 重叠和实验记录共同判断。

## 方法边界与参考

- PCA 中看似分开的点云是人工判断线索，不自动证明存在两个神经元；PC 投影重叠也不能自动证明同一神经元。
- 圈选排除或拆分以后，必须重新应用候选单神经元集合并重新运行受 Unit 影响的下游节点，旧图会被标记为过期。
- 参考工作流：Plexon Offline Sorter 用户手册与产品说明、Phy 手工复核文档、SpikeInterface curation 模块。参考的是功能目的与证据类型，不复制它们的代码、文字或视觉设计。
